# Week 7 student handouts

The easiest download is [Week07_Classroom.zip](../Releases/Week07_Classroom.zip). Extract it and open `START_HERE.md`. It includes the PDFs and numbered examples, with no instructor answers or archive.

| PDF | Use |
|---|---|
| [Class guide](Week_7_Class_Guide.pdf) | One-page route through the class and optional demo setup |
| [Lab 1](Lab_1_Batch_Renaming.pdf) | One sheet per group; wait for the instructor's reveal |
| [Lab 2 peer review](Lab_2_Peer_Review.pdf) | Pages 1 and 3 per student; page 2 per tool attempt |

Print or annotate in a PDF reader. The PDFs do not contain fillable form fields. No installation is needed for the classroom sheets. The separate [Windows Unreal demo](../Releases/Week07_Demo_Windows_UE5.7.4.zip) is optional for trying the tools. Follow its README; PySide is an optional comparison, not a lab requirement.
