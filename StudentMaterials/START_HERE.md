# Week 7 classroom materials

1. Read `Handouts/Week_7_Class_Guide.pdf` for the class route.
2. Print or annotate `Handouts/Lab_1_Batch_Renaming.pdf`. Fill expected results before the instructor reveals the output. No code or installation is needed.
3. Use `Handouts/Lab_2_Peer_Review.pdf` for the three-person review. Each person needs pages 1 and 3; each tool attempt needs one page 2. The rotation guide is on page 1. These are printable PDFs, not fillable forms; use a PDF reader's annotation tools for digital answers.

`Examples/README.md` lists the numbered code examples used in the slides. Read them without installing anything. Run Unreal examples only inside Unreal, Blender examples only inside Blender, and PY01 with ordinary Python. Use the inputs named in the example guide.

Running the demonstrated tools is optional for these classroom sheets. For that, obtain the separate `Week07_Demo_Windows_UE5.7.4.zip`, install Unreal 5.7.4 on Windows and follow its README. The lab packet is not a request to build the native plugin or install PySide.
