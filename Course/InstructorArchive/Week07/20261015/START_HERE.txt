EARLIER PROP-FIXTURE DEMO ONLY (not the primary Material/VFX route)
Output Log / bottom command field: select Python, then run one line at a time:

import week07_tools as w7
w7.select_demo(); w7.camera_view()
w7.inspect_selection()
w7.check()
plan = w7.preview()
w7.apply(plan)
w7.check()

Click the viewport, then Ctrl+Z once to undo the batch; check again.
w7.reset_demo() restores the seeded labels and transforms for rehearsal.
The tool never saves the map. Saving the changed map replaces your on-disk baseline;
reset_demo() and Save restores the intended baseline if that happens.

No selection: produces a warning and no plan.
Unrelated/mixed selection: refuses the plan.
Changed selection / labels / locations after preview: refuses Apply.
Second Apply with a fresh plan: reports zero changes.
Changes affect selected tagged Actor instances, never their shared mesh assets.
The fixture-specific validation checks labels, placement and missing meshes only.
