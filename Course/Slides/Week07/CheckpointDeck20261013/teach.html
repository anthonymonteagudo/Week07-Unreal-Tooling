Prepared demonstrations

Bridge: four-minute execution, following the API setup

Have both prepared scenes and the receiver ready before class. Use Maya for the live publish and revision; use the comparison capture to explain that Blender shares the receiver. First minute: publish baseline and identify its acknowledgement. Second minute: send the prepared revised scene under the same name. Third minute: inspect both instances, dimensions, pivot and materials. Final minute: explain recovery and take a question. If a send stalls for 30 seconds, use the existing comparison capture and verification record. Do not describe the recorded evidence as a fresh live result.

Exact launch commands, prepared scenes and recovery

Material: four-minute execution, following the API setup

Use the current native Tools > Material & VFX Tools panel. First 30 seconds: incomplete texture selection, Preview block, then correct selection. Next 90 seconds: fresh MI_ name, slot zero, Preview and Apply. Next minute: inspect the changed target and protected cube, Undo and inspect the retained instance. Final minute: questions or fallback. Keep the existing detailed run sheet for setup and recovery; its older seven-minute narration is superseded here.

Keep the final minute for questions. Use existing captures if the live setup stalls. No performance claim follows from placement.
