Corrections drawn from the course code

  • The compression fixer defaults to applying fixes across a directory. The lecture instead reports selected texture state and explains the shared-asset consequence.
  • The batch importer uses hardcoded source/destination paths, replacement and saving. The lecture separates these choices and shows the current receiver’s bounded destination and verification.
  • The downloaded remote importer returns True after the import call. The current bridge requires actual returned paths, dimensions and acknowledgement.
  • The prefix validator uses exact class matching for broad asset categories. The lecture uses isinstance for Texture2D eligibility and identifies naming conventions as project rules.
  • The material script clears instance overrides. The classroom example does not copy that destructive setup step.
  • Karol’s Remote Control API example and our folder-based receiver are different transports. The current teaching bridge sends a manifest reference, not executable Python.
