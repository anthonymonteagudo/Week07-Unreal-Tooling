  • 10, 13 and 18: precise shared-asset, handoff and backend relationships. Concrete course props or real crops could strengthen them; generated machinery would add ambiguity.

Ideas to skip

A Python snake wrapped around Unreal, a generic robot pressing buttons, an iceberg for UX, and a maze for “confusing tools” are recognizable but too detached from this deck’s specific tasks. Likewise, a padlock would overstate tool safety, and a rewind symbol would imply universal Undo.

Field-level proposal

Composition

Read-aloud notes
