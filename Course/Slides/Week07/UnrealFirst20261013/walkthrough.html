1. Prepare the material comparison

  1. Open Week07UnrealPython.uproject, then /Game/Week07/Maps/W07_MaterialVFXLab. Stop Play in Editor.
  2. Identify W07_Crate_Target and W07_Crate_Protected. Inspect their current material before changing anything.
  3. Locate /Game/Week07/LiveDemo/Textures and the three T_Crate_ textures: BaseColor, Normal and ORM.
  4. Locate /Game/Week07/LiveDemo/Materials/M_PreparedSurface. This parent exposes the three texture parameters below.
  5. Keep the Output Log in Python mode. Execute complete checkpoint files from Tools → Execute Python Script, or copy a complete file from the guide.

Say: “We are going to inspect the texture, choose the material inputs, and assign the result to one placement. Those are three different kinds of state.”

2. Texture settings: inspect first

Double-click a texture in the Content Browser. In its Details panel, search the exact setting name if its category is collapsed. These are texture-asset properties shared by every material using that texture. Epic: Texture Asset Editor.

Run UE05 with the three textures selected. Compare the printed values to the editor. Run UE06 to report every selected _Normal texture with the wrong compression. A zero checked count is inconclusive. The full tool also checks the set’s matching names, sRGB values and required parameters.

Manual correction: choose the intended value in the texture editor, review its effect on shared users, and save only after verification. The assistant deliberately requires this review instead of silently changing a shared texture. Keep the prepared textures unchanged during the read-only checkpoint.

Say: “sRGB tells Unreal how to interpret color values. Normal and ORM encode data. A filename gives us a rule to check, but does not prove what is inside an image.”

3. Material instance: choose the texture references

  1. Right-click M_PreparedSurface in the Content Browser and choose Create Material Instance. Give it a fresh MI_ name and open it.
  2. In Details → General, inspect Parent. In Parameter Groups, enable each texture override and select its matching texture.
  3. Inspect the preview and parameter values. Save intentionally after review. To compare with the tool, use a different fresh name; the tool refuses an existing destination.
Parameter set by the toolTexture selectedPrepared parent graph

The backend creates a MaterialInstanceConstant, calls set_material_instance_parent, then calls set_material_instance_texture_parameter_value for each mapping. It reads the values back and updates the instance. Run UE09 with the resulting instance selected to inspect those same references.

The tool changes texture references. It does not build the parent graph, set separate roughness/metallic scalar controls, change the shading model or edit Niagara graphs. The named inputs and ORM routing are this course parent’s design, not automatic universal parameter names. Epic: instance parameters and Parent control · Actual prepared graph source.

4. Material assignment: change one placement

  1. Select W07_Crate_Target in the Outliner, select its Static Mesh component, then find Details → Materials → Element 0.
  2. Choose an existing material or material instance. Inspect the target and the protected cube. Undo once over the level viewport to return to the previous assignment.
  3. Select that same material in the Content Browser and only the target Actor in the Outliner. Run UE08. It checks the map, target and slot, then performs component.set_material(0, material) within an Undo transaction.
  4. Inspect both cubes, rerun once to see the no-change result, then Undo the original assignment.

The edited state is a component material override. Changing Static Mesh Editor → Material Slots instead changes the mesh’s shared default. Editing the material instance’s parameters can affect every user of that instance.

Full assistant: Tools → Material & VFX Tools. Select the three textures and the target, choose the prepared parent, fresh MI_ name and slot 0, then Preview and Apply. Inspect the new instance and its target. Undo restores the component assignment but leaves the created instance asset. The backend does not automatically save that draft asset. 6. Bridge verification includes materials

Both publishers send an FBX and a manifest. The Unreal receiver imports geometry with import_materials=False and import_textures=False. On an existing bridge mesh it restores static_materials. Existing Actor component overrides remain associated with their placements. This prepared one-mesh example does not establish preservation across arbitrary material-slot topology changes.

Before and after revision, record the shared mesh path, both Actor placements, mesh slot assignments and component overrides. The geometry should update in both instances while their Unreal materials remain. No source shader-network transfer is implied. Follow the Maya walkthrough · Receiver source.
