Triangle Count Validator — REFINED

Course index · Original notes

Check a mesh's recorded triangle count against a project budget. The course uses Asset Registry tags, avoiding a custom traversal of mesh sections just to obtain a count already recorded by Unreal.

Locate the recorded count

Compare the more involved Blueprint counting example with the triangle information shown in asset tooltips and the mesh editor.

Read and convert the registry tag

The screenshot's Triangles tag is registry data, not a triangle count obtained by traversing mesh geometry. In the demonstrated approach, convert an object path to a package path, use an Unreal name for the tag key, and convert the returned string before comparing:

package_path = asset.get_path_name().rsplit(".", 1)[0]
tags = unreal.EditorAssetLibrary.get_tag_values(package_path)
key = unreal.Name("Triangles")
if key not in tags:
    result = unreal.DataValidationResult.NOT_VALIDATED
else:
    triangle_count = int(tags[key])
    result = (unreal.DataValidationResult.INVALID if triangle_count > 2500
              else unreal.DataValidationResult.VALID)

This is the decision fragment inside the course validator (asset and unreal are supplied there). Keep its pass/fail logging too. The example budget is 2,500 triangles; it is not a universal asset budget or a proof of runtime performance.

EditorAssetLibrary.get_tag_values() retrieves Asset Registry tags by asset path. These tags differ from the custom metadata used for import rules.

Implement eligibility and lookup

Create an EditorValidatorBase subclass that accepts static and skeletal meshes. Obtain a package path in the form expected by get_tag_values(); the recording strips the final object-name portion to avoid its engine version's object-path warning.

If Triangles is missing, report a warning and return NOT_VALIDATED. Do not treat missing data as a successful count check.

Compare against a budget

Tag values are strings, so convert Triangles to int before comparing. The example uses TRIS_COUNT_MAX = 2500. If the count exceeds the limit, call asset_fails() with both the measured count and limit, then return INVALID; otherwise return VALID.

Different categories may need different budgets. Choose them from folder structure or metadata, or use separate validators whose eligibility checks target each category.

Register and verify

Instantiate the validator, add it to EditorValidatorSubsystem, and run validation on the test folder.

The demonstrated statue has 4,024 triangles and fails the 2,500-triangle limit. The error includes the count and threshold so the required change is clear.
