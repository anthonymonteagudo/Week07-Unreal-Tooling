Introduction to Remote Control — REFINED

Course index · Original notes

Remote Control provides a way for an external interface or application to interact with Unreal. The course follows two workflows:

  • Presets and the web interface: expose scene properties and controls for tasks such as virtual-production lighting, camera adjustment, and branding.
  • Direct API calls: invoke exposed functions from another application, including Python pipeline tools, without requiring a preset UI.

Enable Remote Control API. Enable Remote Control Web Interface as well for the browser UI, then restart the editor. Protocol plugins such as OSC, MIDI, or DMX are additional integrations rather than requirements for the basic HTTP examples.

The direct-call examples use HTTP requests with JSON containing an objectPath, functionName, and optional parameters. The following lessons first build a preset interface, then expose Python functions and a remotely controlled progress dialog.
