Getting User Selection and Listing Assets — REFINED

An asset is content stored in the project, such as a static mesh. An actor is an object placed in a world; a static mesh actor references a mesh asset. Changing an actor's transform affects that instance, while changing its referenced asset can affect every instance using it.

Keep the selected objects and their identities distinct

This compact example connects the selection, path, and loading operations shown below:

import unreal
for asset in unreal.EditorUtilityLibrary.get_selected_assets():
    object_path = asset.get_path_name()
    unreal.log(f"{asset.get_name()} | {object_path} | {asset.get_class().get_name()}")
    # Selection already supplied a loaded object. Load only when starting from a path:
    same_asset = unreal.EditorAssetLibrary.load_asset(object_path)

These are Content Browser assets, not actors selected in the level. An object path such as /Game/Props/SM_Crate.SM_Crate is also different from a disk filename or folder/package path.

List and load assets

Use EditorAssetLibrary.list_assets() with an Unreal content path such as /Game/StarterContent/Architecture. Check the API's return type: this call returns paths, not loaded objects. Load an asset with load_asset() before inspecting or editing its properties.

Unreal exposes several representations:

  • Package path: /Game/Folder/Asset.
  • Object path: /Game/Folder/Asset.Asset.
  • get_full_name(): class plus object path, useful for debugging.
  • get_path_name(): the object's path.
  • get_fname(): its Unreal Name.

The lesson shows a warning when a function receives an object path where a package path is expected. Match the path form to the receiving API rather than assuming all path strings are interchangeable.

find_asset_data() exposes asset metadata. For loaded objects, isinstance(asset, unreal.StaticMesh) provides a straightforward type check.

Get actors through the editor subsystem

The course's UE 5.3+ correction replaces direct subsystem construction with:

actors_subsystem = unreal.get_editor_subsystem(unreal.EditorActorSubsystem)
actors = actors_subsystem.get_all_level_actors()
selected = actors_subsystem.get_selected_level_actors()

Subsystem methods require the appropriate instance. Calling one as if it were a static library function can produce a missing-argument error; inspect the signature when moving between Unreal libraries and subsystems.

Actor queries return objects already in the level, so they can be filtered directly with isinstance().

Select actors in the Outliner, then compare get_selected_level_actors() with that selection.

Content Browser selection and reference example

Use EditorUtilityLibrary.get_selected_assets() for loaded selected assets, or get_selected_asset_data() when asset-data records are sufficient. The captured reference script collects these alongside the listing and actor examples.
