Batch Importing Textures with AutomatedAssetImportData — REFINED

Course index · Original notes

For imports that need fewer custom options, use one AutomatedAssetImportData object containing all source paths. import_assets_automated() returns the imported objects for immediate processing.

Gather the source textures

Choose the disk source folder and Unreal destination, such as /Game/Enviro. The example finds PNG files with Path(source_folder).glob("*.png").

Automated import data and the returned assets

The alternative API takes one configuration object and returns imported objects, rather than returning the task list from lesson 19:

import unreal
data = unreal.AutomatedAssetImportData()
data.set_editor_property("filenames", ["C:/Exports/T_Example.png"])
data.set_editor_property("destination_path", "/Game/Imported")
data.set_editor_property("replace_existing", True)
objects = unreal.AssetToolsHelpers.get_asset_tools().import_assets_automated(data)
for asset in set(objects):
    unreal.log(asset.get_path_name())

The set removes duplicate returned object references; it does not merge or delete assets. Adapt the filenames and replacement policy before running the example.

Prepare import data

Find AssetTools.import_assets_automated() and its expected AutomatedAssetImportData argument. Set destination_path, filenames, and replace_existing.

Convert pathlib.Path values to strings before assigning filenames. The lesson uses list(map(lambda path: str(path), paths)); [str(path) for path in paths] expresses the same conversion.

Run and return the objects

Get Asset Tools with AssetToolsHelpers.get_asset_tools(), then call import_assets_automated(import_data). The demonstration converts the returned objects to a set to remove duplicate results observed during testing. A set does not preserve a useful import order.

Wrap the operation in batch_import_textures(destination_path, source_folder) and return the imported objects. A main entry point can call the function and print the result.

Verify the result

The course resets its test destination, executes the script, and checks both the Output Log and imported textures. Compare the resulting content with the source folder.

Use AssetImportTask from lesson 19 when per-file or asset-specific options require more control.
