Python Scripts in Asset Scripted Action Blueprints — REFINED

Course index · Original notes

An Asset Action Utility can expose a simple Content Browser action and parameter dialog while Python performs the asset work. This example assigns a chosen material instance to every material slot on selected static-mesh assets.

Create the utility

Enable Editor Scripting Utilities alongside the existing Python setup. Create an Editor Utility Blueprint based on AssetActionUtility; ActorActionUtility is the corresponding option for level actors. Use an Editor Utility Widget when a more elaborate interface is needed.

Pass selected assets into Python

Create an AssignMaterial custom event and enable Call in Editor. Connect Get Selected Assets to an input named selected_assets on Execute Python Script. Iterate the incoming Unreal array directly; converting it to a Python list is unnecessary for a simple loop.

The conversion slide is conceptual: typed Unreal arrays require the appropriate typed construction/cast, as discussed in lesson 19. Import required modules inside the Python node. During development, importlib.reload can reload edited modules, but existing state or references may still need attention.

Compile, save, and run the action through Scripted Asset Actions. Printing the selection confirms that the node receives objects rather than paths that must be loaded again.

Add the material picker and assignment

Add a MaterialInstance object-reference input to the event. Unreal creates a picker in the action's parameter dialog. Add the matching material_instance input to the Python node and connect it.

For each supported static mesh, iterate its material slots and call set_material:

import unreal

for asset in selected_assets:
    if isinstance(asset, unreal.StaticMesh):
        for slot_index in range(len(asset.static_materials)):
            asset.set_material(slot_index, material_instance)

This changes the mesh asset's material slots, affecting its uses; it is not an actor-only material override. Validate the supplied material before applying the change.

Return a result and check the assets

Add a Boolean output, assign result = True when the operation completes, and connect that output through Boolean-to-string conversion to Print String. Ensure it reaches the string input rather than the world-context input.

Node execution and result wiring

Use Shift+Enter for a newline while editing the Python script field. Keep import unreal inside the node's code. An optional Is Python Available branch can produce an understandable fallback when Python is unavailable.

An output pin named result receives a Python variable assignment such as result = True; this is not a return statement at the top level. Set a meaningful result only after the intended work completes. The node's execution-success output says the script executed successfully, which is different from proving that every selected asset satisfied the tool's requirements.

Run the action, select a material, and inspect the asset previews, material slots, and returned value.

Restrict where the action appears

Without a class restriction, the action can appear for unsuitable assets, as in this material selection.

In Class Defaults → Supported Classes, add StaticMesh. Check that the action disappears for unsupported selections and remains available for meshes. Retain the Python type check as well.
