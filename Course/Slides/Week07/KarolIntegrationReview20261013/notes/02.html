VS Code Autocomplete Setup — REFINED

Course index · Original notes

Configure VS Code to read the unreal.py stub generated in lesson 01. The course demonstrates UE 5.1 with Python 3.9.7; match the interpreter to your own engine version rather than treating that version as universal.

Install Python support

Install Microsoft's Python and Pylance extensions. Restart VS Code if prompted.

Select the appropriate Python interpreter. The demonstrated settings expose it under Python → Default Interpreter Path.

Add the stub folder

Open the extra-path settings and add <Project>/Intermediate/PythonStub, the folder containing unreal.py. In JSON, quote the path and use forward slashes or escaped backslashes.

Restart VS Code. The lesson shows both python.autoComplete.extraPaths and python.analysis.extraPaths pointing at the stub folder after restart.

Confirm autocomplete and navigation

Create a Python file, enter import unreal, and type unreal.. Allow time for the large stub to load; completion suggestions should appear.

Ctrl-click an Unreal symbol to inspect its definition, parameters, and inheritance in the stub.

If the generated stub gives unclear or inconsistent type information, compare it with the Python API documentation for the same engine version.
