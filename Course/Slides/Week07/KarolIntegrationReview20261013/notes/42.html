Remote Control Preset and Web App — REFINED

Course index · Original notes

Build a browser interface that changes a demonstration scene's driver text, car color, lighting, and camera. The course's starting project uses Unreal 5.3.

Prepare the scene and plugins

Enable Remote Control API and Remote Control Web Interface, then restart. The virtual-production template may already enable the API while leaving the web interface disabled.

For the demonstration camera, enable Look at Tracking and select the car actor. Set focus to Tracking and use the same actor so camera movement preserves its subject and focus.

Expose and group properties

Create a Remote Control Preset from the Content Browser. Use the eye/expose control beside an actor property to add it; the additional options can expose a sub-property such as one location axis.

Create a Camera group for location, focal length, and aperture. Move existing entries from All into that group. If entries seem to disappear, check and reset the preset's filters.

Create a Lights group, then expose the spotlight's location, intensity, and color. Newly exposed properties are added to the active group.

Create Team Branding for the driver text, text color, and car-paint color. To expose a material parameter, create and assign a material instance, open it, and expose its BaseColor vector parameter. Exposing the actor's material slot instead would allow replacing the material, rather than adjusting its color.

Save the modified scene/assets and preset before building the interface.

Build the browser interface

Click Web App, choose Build Your Own UI, switch from Control to Design, and select the preset. Project Settings contains separate web-interface/server settings; check the configured port if the page cannot open.

Drag properties or whole groups onto the canvas to create connected widgets. Rearrange related controls together and choose appropriate widget types: color pickers, text fields, dials, sliders, or location joysticks.

Tune ranges and labels

Set usable ranges for the scene. The demonstration uses aperture 1.2–32 and focal length 8–300; these are example control limits. Adjust light-intensity limits to suit the scene too.

Switch back to Control and verify that each widget changes the intended scene property.

The preset's property details can also define widget type, range, and description. Give similar properties clear names such as Camera Location and Light Location so the operator can distinguish them.
