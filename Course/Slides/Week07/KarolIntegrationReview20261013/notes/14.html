Editing Material Instance Parameters — REFINED

Course index · Original notes

Material parameters are exposed by the parent material's author. Use MaterialEditingLibrary to access them; they are not interchangeable with ordinary editor properties.

Create a suitable instance

Choose a material with exposed parameters and create a material instance. The course uses a Starter Content material with two emissive color parameters.

Discover names and parameter types

MaterialEditingLibrary has separate getters and setters for different parameter types. Use get_vector_parameter_names() to retrieve the color parameter names, preserving their exact spelling and spaces.

Set a vector parameter with set_material_instance_vector_parameter_value(), passing the instance, parameter name, and color value. The lesson uses [0.1, 0.2, 0.3, 0.4]. Open the instance and inspect the values even if its thumbnail has not refreshed.

Make repeatable edits

The reusable script loads a MaterialInstanceConstant and wraps the setter in a helper that checks whether the parameter exists. A missing parameter should be reported clearly rather than silently producing partially configured assets.

Decide whether existing overrides should be retained. The demonstration calls clear_all_material_instance_parameters() before assigning its two colors, making the result independent of earlier edits. That operation clears other overrides too, so it must be an intentional part of the tool's behavior.

Return the setter's success value, and use update_material_instance() when an instance update is required after the edits.

Parameter names, values, and return values

The final screenshot uses vector parameters named Emissive Color 01 and Emissive Color 02, with four-component color values. This cleaned-up equivalent checks both names before clearing existing overrides:

import unreal
mel = unreal.MaterialEditingLibrary
instance = unreal.EditorAssetLibrary.load_asset(
    "/Game/StarterContent/Materials/example_instance")
values = {"Emissive Color 01": (0.1, 0.2, 0.3, 0.4),
          "Emissive Color 02": (0.1, 0.2, 0.3, 0.4)}
available = {str(name) for name in mel.get_vector_parameter_names(instance)}
missing = set(values) - available
if missing:
    raise ValueError(f"Missing vector parameters: {sorted(missing)}")
mel.clear_all_material_instance_parameters(instance)
for name, channels in values.items():
    changed = mel.set_material_instance_vector_parameter_value(
        instance, name, unreal.LinearColor(*channels))
    unreal.log(f"{name}: setter returned {changed}")
mel.update_material_instance(instance)

Use an instance whose parent exposes those exact names. Clearing removes all instance parameter overrides, not just these two. The course helper returns the setter's Boolean; inspecting the resulting parameter values remains necessary. This example updates the instance but does not explicitly save it.

Run and inspect

Execute the saved script, reopen the instance, and confirm both parameter overrides and their values.
