Packaging the Python Tool as an Unreal Plugin — REFINED

Course index · Original notes

Combine the texture-compression validator, context-menu entry, icon, and progress dialog into a distributable plugin. Keep the validation logic separate from editor UI setup.

Create the plugin and Python folder

The finished tool appears in Plugins and adds Fix Compression Settings to a texture's context menu. Its Output Log reports the processed textures.

Create the FixTextureCompression plugin and fill in its version, category, author, and documentation details. Enable plugin content in the Content Browser, create Content/Python, and add that folder to the IDE's content roots.

The package's __init__.py and Unreal's startup file init_unreal.py serve different purposes. The latter will register the menu when Unreal initializes Python.

Module layout and startup call

A minimal arrangement matching the lesson is:

FixTextureCompression/
  FixTextureCompression.uplugin
  Content/Python/
    init_unreal.py
    fix_compression.py
    setup_fix_compression_ui.py

init_unreal.py imports setup_ui from setup_fix_compression_ui and calls it. If using a package subfolder instead, retain its __init__.py and use package-qualified imports. Keep the core module free of startup/menu side effects.

The original normalization checks isinstance(assets, list) and wraps anything else in a list. That supports a single texture and a Python list, but an Unreal array would be wrapped as one item. The demonstrated menu avoids this by looping over selected assets and passing one texture at a time. For a batch API, deliberately convert the selection with list(selection) or support Unreal arrays explicitly.

Adapt the core function to selected objects

Copy the existing validator into a clearly named module such as fix_compression.py. Remove obsolete demonstration code and the directory-based script entry point.

Change the input to accept a Texture2D or a list of textures. Normalize a single texture to a list, skip unsupported objects, and use the already-loaded objects instead of loading asset paths again. Retain the suffix-to-compression mapping and apply_fix behavior; use the texture's name in log messages.

Connect selection and progress

In the UI module, the menu callback gets selected assets and processes each texture with the core validation function. Use ScopedSlowTask with the selection count, show a cancellable dialog, check cancellation in the loop, and advance progress by one per item.

Register the texture menu entry

Put registration in setup_ui() inside setup_fix_compression_ui.py. Target ContentBrowser.AssetContextMenu.Texture and its GetAssetActions section. Set the label, tooltip, and icon, then connect the execution callback.

The course locates the Checker brush in EditorStyle, avoiding a dependency on an optional plugin's icon. Verify the style and brush names against the demonstrated engine resources.

Initialize and verify

Have init_unreal.py import and call setup_ui(). Restart Unreal, test the menu with one texture and then a multi-selection, and inspect both the changed settings and log output.
