Editor Property Change Notifications — REFINED

Course index · Original notes

Setting a visible property value is not always enough: Unreal may also need an editor change notification to rebuild dependent data. The example changes a texture's source color space and exposes a failure that produces no obvious Python exception.

Establish a working manual result

Import separate copies of a texture. On one copy, change Source Color Settings → Color Space to sRGB manually, save, and reopen it. Keep that copy as a reference.

Reproduce the scripted failure

Load another copy and inspect the Texture2D, source-color-settings, and color-space properties in the stub.

The direct assignment shown in the lesson updates texture.source_color_settings.color_space, then saves the texture. Although the visible value changes, the texture turns black because the dependent chromaticity values were not regenerated.

Compare the manually edited and scripted assets, including their dependent properties. Toggling the setting manually can reveal the missing update.

Reading the outer property with get_editor_property() does not fix a later direct assignment to the inner property. The write itself needs the appropriate notification.

Notifying nested-property write

The key difference in the successful screenshot is the inner property's setter, not just how the outer struct was read:

import unreal
texture = unreal.EditorAssetLibrary.load_asset("/Game/Textures/T_Example")
settings = texture.get_editor_property("source_color_settings")
settings.set_editor_property(
    "color_space", unreal.TextureColorSpace.TCS_S_RGB,
    notify_mode=unreal.PropertyAccessChangeNotifyMode.ALWAYS,
)
unreal.EditorAssetLibrary.save_loaded_asset(texture)

Replace the illustrative asset path. This is the course's source-color-space example, not a general instruction to change every texture to sRGB. Compare the resulting appearance and dependent values with the manual reference.

Set the edited property with notification

Call set_editor_property("color_space", ...) on the source color settings, then save the texture. The lesson demonstrates PropertyAccessChangeNotifyMode.ALWAYS to force notification.

The modes are:

  • DEFAULT: notify when the value changes.
  • ALWAYS: notify even when the assigned value is unchanged.
  • NEVER: suppress the change notification.

On a fresh texture, NEVER reproduces the black result. Using the notifying setter restores the expected appearance and chromaticity values.

When scripted and manual edits differ, compare the resulting asset state instead of checking only the property you assigned.
