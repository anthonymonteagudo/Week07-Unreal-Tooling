Startup Scripts and init_unreal.py — REFINED

Course index · Original notes

Use startup scripts to initialize tools, register callbacks, or configure shared paths when Unreal starts.

Automatic initialization

Create init_unreal.py in a discoverable Python directory, such as <Project>/Content/Python. Add a distinctive log message so you can confirm that it executes.

Register a named startup script

Create a separately named script, such as startup_script.py, with a different log message.

Add it under Project Settings → Python → Startup Scripts. A discoverable script can be entered by filename. Restart Unreal to apply the setting.

Verify both entry points

Search the Output Log for the messages from both files. If the log is noisy, use Filters → Categories → LogPython to narrow the output.
