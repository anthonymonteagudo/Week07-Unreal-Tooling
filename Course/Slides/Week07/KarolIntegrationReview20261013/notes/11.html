Filtering Assets and Actors with EditorFilterLibrary — REFINED

Course index · Original notes

EditorFilterLibrary provides reusable filters for object lists. Some work on both assets and actors; others target actor labels, tags, or asset names specifically.

Prepare object lists

List asset paths and load them into an asset list. Retrieve level actors through EditorActorSubsystem. These filters operate on objects, not on the path strings returned by list_assets().

A simple Python equivalent for filtering static meshes is:

meshes = [asset for asset in assets if isinstance(asset, unreal.StaticMesh)]

Include or exclude a class

Call EditorFilterLibrary.by_class() with the object list and desired Unreal class. EditorScriptingFilterType.INCLUDE keeps matches; EXCLUDE keeps everything else. Convert the returned Unreal array with list() when useful for inspection.

Match names

by_id_name() supports these EditorScriptingStringMatchType choices:

  • CONTAINS: match a substring, such as Effect.
  • EXACT_MATCH: match the entire name, such as Blueprint_Effect_Fire.
  • MATCHES_WILDCARD: match a pattern, such as Blueprint_Effect_*.

An exact search for only Effect will not match a longer name containing that word.

Choose for clarity, then measure

The lesson's timings favor a Python comprehension for class filtering but the library for name filtering. These are measurements of particular examples, not a universal ranking. Prefer readable code, and benchmark the actual workload if filtering becomes a bottleneck.
