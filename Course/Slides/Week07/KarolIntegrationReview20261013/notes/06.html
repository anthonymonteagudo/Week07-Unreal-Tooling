Making Scripts Discoverable by Unreal — REFINED

Course index · Original notes

Unreal must be able to find a Python module before you can import it. Keep project scripts in <Project>/Content/Python for a portable, self-contained setup.

Try the Python console

Open Output Log, change the command mode to Python or Python REPL, and run a simple command.

Minimal script to reproduce the result

Save this as Content/Python/hello.py, then execute the saved file from Unreal:

import unreal
unreal.log("Hello Unreal")

The unreal module comes from the editor's embedded interpreter. Selecting Unreal's Python executable in an IDE does not turn a standalone terminal process into the editor.

Choose a script location

The course lists these discoverable locations:

  • Content/Python inside the project, engine installation, or an enabled plugin.
  • Documents/UnrealEngine/Python inside the user's directory.

For a custom location, add its directory under Project Settings → Python → Additional Paths, then restart.

The course also demonstrates environment-variable paths through UE_PYTHONPATH or PYTHONPATH. Availability depends on the Python environment configuration shown in the settings.

For a session-only path, append the directory containing your modules to sys.path:

import sys
sys.path.append("C:/MyTools/Python")

To repeat that setup on startup, put it in a registered startup script or in a discoverable init_unreal.py. The directory belongs on sys.path, not the path to an individual .py file.

Create and import a test module

Enable Show Empty Folders in the Content Browser if needed. Developer, plugin, and engine content visibility can also help when navigating script locations. Create Content/Python and open that directory in your IDE.

Create hello.py there. Python files exist on disk but are not Unreal assets, so they will not appear as normal Content Browser assets.

Define a say_hi() function using unreal.log(), with a separate top-level print() to make the initial import visible.

Restart if needed, import hello, then call hello.say_hi(). Check the Output Log for both messages.

Unreal engine has a built in Python command support similar to the one in programs like Maya or Blender.

If you are experimenting or want to execute a few lines of code, all you need to do is to open output

log, switch command line mode to Python or Python Repl and type some command.

It may be sufficient at the very beginning, but sooner or later you will want to share your scripts

and be able to run them quickly, or even make tools from them, or have some shared modules.

In that case, before even running a script, you want it to be discoverable by the engine.

It's best to keep your scripts in content slash Python subfolder of your project, or the main unreal

installation, or any plugin that you want to modify.
