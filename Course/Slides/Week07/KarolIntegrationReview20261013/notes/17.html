Post Import Actions with ImportSubsystem — REFINED

Course index · Original notes

Use ImportSubsystem when you need a small custom callback or want to manage import processing directly. Register the callback from init_unreal.py so it is available each editor session.

Choose the import event

The course covers post-import, post-LOD-import, pre-import, and reimport events. Post-import can run for both a first import and a reimport; it does not mean “first import only.”

Register a callback with the correct signature

Get the subsystem with unreal.get_editor_subsystem(unreal.ImportSubsystem), then register a callable on on_asset_post_import. The demonstration keeps a module-level subsystem reference to avoid the callback-lifetime problem encountered during development.

The post-import callback receives factory and created_object. The factory can be None, and the documented created object can be null when import fails; check the object before using it.

Call the registration function from init_unreal.py.

Test import and reimport

Drag in a test texture, inspect the callback log, then reimport it. The log shows the callback running in both cases.

Track whether processing has run

Read the importer_rules_applied metadata tag and compare its string value with "True". After processing, set the tag to "True". This distinguishes previously processed assets from first-time processing; it is a stored marker, not a separate first-import event.

Move tagged meshes

Reuse the FBX.mesh_type lookup and folder mapping from lesson 16. Build a destination that preserves the asset name, then move it with rename_asset(). Add an early return for objects that are not unreal.StaticMesh.

Import a texture to confirm it is skipped, then import the example mesh to confirm its destination and metadata.

Prevent duplicate registration

Registering the same callback repeatedly can run the operation multiple times per import. The example uses a module-level registered_once flag and an early return. Keep registration ownership explicit as the tool grows.

Reimport marker and callback lifetime

The importer_rules_applied metadata value records prior processing. In the demonstrated callback, finding the marker logs that this is a reimport; it does not return early, so the move logic still runs. If the intended rule is first-import-only, an explicit early return is a separate behavior change.

The registered_once flag prevents another registration only while that module's state survives. Reloading a module that resets the flag can register another callable. Retain the subsystem and callback references, and remove the previous callable when deliberately replacing a registration. The folder mapping in the completed example is environment → Enviro, weapons → Weapons, and deco → Deco; unmatched names should not be assigned a guessed category.
