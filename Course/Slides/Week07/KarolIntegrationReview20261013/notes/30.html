Adding a Menu Entry Icon — REFINED

Course index · Original notes

Add a registered Slate icon to the menu action from lesson 29. The assignment differs depending on whether the tool uses a ToolMenuEntry or a ToolMenuEntryScript.

Access the icon data

For a ToolMenuEntry, use set_icon(). For a script entry, init_entry() does not return a menu-entry object; access script_object.data.icon instead.

Create a ScriptSlateIcon with three identifiers:

  • style_set_name: the registered Slate style set.
  • style_name: the regular icon's style key.
  • small_style_name: the small icon's style key.

Find an existing Slate style

The lesson mentions C++ style registration for custom icons, then uses a built-in style. Inspect the relevant style source file to find both the style-set name and the icon keys.

The demonstrated palette icon uses UMGStyle, Palette.Icon, and Palette.Icon.Small.

Assign and refresh

Assign the constructed icon to the script entry's data before refreshing menu widgets:

script_object.data.icon = unreal.ScriptSlateIcon(
    style_set_name="UMGStyle",
    style_name="Palette.Icon",
    small_style_name="Palette.Icon.Small",
)
menus.refresh_all_widgets()

Run the registration script, open the context menu, and check the icon beside the action. A missing icon can indicate that its style set or key is unavailable in that context.
