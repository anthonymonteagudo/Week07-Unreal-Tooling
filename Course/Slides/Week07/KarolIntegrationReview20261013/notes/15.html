Finding Duplicated Actors on a Level — REFINED

Course index · Original notes

Find overlapping copies by comparing the referenced mesh and actor transform. Actor names alone are unreliable: duplicate instances can have different names and remain visually indistinguishable.

What the duplicate comparison actually establishes

The workflow groups static-mesh actors by their referenced mesh, then compares transforms within each group. Two different meshes at the same transform are not duplicates under this rule. Matching mesh and transform identifies a candidate; other actor/component settings can still differ.

Read the successive screenshots as: collect actors → retain static meshes → group by mesh → compare transforms → report/select candidates. Keep one representative when handling a group, rather than flagging every member for removal. The comparison is a scene-placement rule, not a geometry-similarity test.

Gather static mesh actors

Use unreal.get_editor_subsystem(unreal.EditorActorSubsystem) to obtain level actors, following the UE 5.3+ correction in the course. The earlier direct-constructor example is retained in the screenshots for context.

For a StaticMeshActor, access its static_mesh_component.static_mesh to identify the underlying asset. More complex actors may require get_components_by_class() or another component query.

Group by the referenced mesh

Skip actors outside the supported class. Group the remaining actors by their static mesh asset, then discard groups containing only one actor: they cannot contain duplicates of that mesh.

Compare transforms within each group

Use Transform.is_near_equal() to compare location, rotation, and scale. Adjust the tolerances only to match the intended definition of a duplicate.

For each mesh group, choose a reference actor and compare it with the remaining candidates. Collect near-equal actors into a cluster, keeping that cluster only when it contains at least two members. A single mesh can have multiple duplicate clusters at different locations.

The demonstrated implementation iterates backward while removing reference actors, and tracks matched indexes so the same actors are not reported repeatedly. Keep index handling consistent when mutating the list.

Report actionable results

Print each cluster's actor identifiers, mesh asset, and world location, with separators between clusters. The example reports floor and statue duplicates; use the identifiers and locations to find them in the level. A CSV export can make a larger report easier to review.
