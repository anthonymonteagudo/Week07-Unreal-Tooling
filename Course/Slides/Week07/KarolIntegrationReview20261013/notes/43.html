Remote Control Preset Controllers — REFINED

Course index · Original notes

Controllers let one input drive several exposed properties. Use them to replace repeated manual changes, such as updating the driver name, text color, and car paint together.

Apply team settings with conditions

Open the preset's Logic view, add a string controller named Team, and attach a Conditional behavior.

For the yellow-team condition, add actions for driver text, text color, and car-paint color, then set the desired values. Drag exposed properties into the action list or choose them with the add control. Enter the matching team value to test all three changes together.

Add a second condition and action set for the red team. An Else condition can provide a fallback. The On Modified behavior instead runs its actions whenever the controller changes; the lesson demonstrates setting a light's color this way.

Bind several properties to one value

Drag an exposed color property into the controller list to create a controller with a Bind behavior. Add another compatible color property to that binding so a single color adjustment affects both. This is useful for coordinated lights or branding colors.

Use distinct controller names to separate a shared control from each individually exposed property.

Expose a function for more complex behavior

Use the preset's function control to expose a Blueprint library or actor function. The demonstration adds Print String, calls it, checks Output Log, and expands its parameters to change the message.

A function can support more involved actions, such as triggering an animation or effect, while the preset provides the button.

Add controllers to the web UI

In the web app's Design mode, add the exposed function and controls. The Controllers group supplies the shared color control; the original properties still allow individual adjustments. Verify that the shared controller updates all bound values and rename it clearly.
