Remote Debugging with VS Code and debugpy — REFINED

Course index · Original notes

Attach VS Code to Unreal's Python interpreter to pause at breakpoints, step through execution, and inspect variables. The course packages debugpy in a project plugin so its installation can be shared and enabled separately from other debugger packages.

Inspect Unreal's debugging helper

Open PythonScriptPlugin/Content/Python/debugpy_unreal.py in the engine installation. It contains the helper functions and an example attach configuration. Add the project's Content/Python folder to the VS Code workspace as well.

Create a plugin for the package

In Edit → Plugins → Add, create a content-only plugin such as DebugpyPythonPackage. Enable it and optionally place it in the Scripting category.

Enable Show Plugin Content, find the plugin, and open its content directory in Explorer. Create Content/Python inside the plugin and copy that path.

Install with Unreal's interpreter

In Unreal, obtain the interpreter path with unreal.get_interpreter_executable_path(). Use that interpreter to ensure pip is present, then install debugpy into the plugin's Python directory with pip install --target.

Installation and attach configuration in copyable form

In Unreal, obtain the interpreter path with unreal.get_interpreter_executable_path(). In a PowerShell terminal, use that path and the plugin folder you created:

& 'C:/Path/To/Unreal/Python/python.exe' -m ensurepip
& 'C:/Path/To/Unreal/Python/python.exe' -m pip install --target 'C:/MyProject/Plugins/DebugPy/Content/Python' debugpy

Enable the plugin and restart Unreal. Import debugpy to check discovery, then follow the installed debugpy_unreal.py helper's instructions. The lesson calls debugpy_unreal.start() inside Unreal and attaches from VS Code; waiting for attachment can make the editor appear frozen.

This is the course-style .vscode/launch.json structure with machine-specific paths replaced. The historical extension uses "type": "python"; use the attach type generated by your installed VS Code debugger if it differs.

{
  "version": "0.2.0",
  "configurations": [{
    "name": "Unreal Engine Python",
    "type": "python",
    "request": "attach",
    "connect": {"host": "localhost", "port": 5678},
    "pathMappings": [
      {"localRoot": "C:/MyProject/Content/Python", "remoteRoot": "C:/MyProject/Content/Python"},
      {"localRoot": "C:/UE/Engine/Plugins/Experimental/PythonScriptPlugin/Content/Python",
       "remoteRoot": "C:/UE/Engine/Plugins/Experimental/PythonScriptPlugin/Content/Python"}
    ],
    "redirectOutput": true,
    "justMyCode": false
  }]
}

Match the helper's actual port and map every root whose breakpoints you need. Set a breakpoint in the target script and execute that script in Unreal after attaching. Continue resumes the editor; step-over and variable/call-stack inspection explain the later screenshots.

Restart Unreal, verify the plugin is still enabled, and test import debugpy. If the module is missing, check the enabled state and target folder before reinstalling.

Keeping different debugger packages in separately enabled plugins helps avoid conflicts between their underlying dependencies.

Configure VS Code attachment

Use Run and Debug → Create launch.json → Remote Attach. Store the configuration in the project or workspace. The recorded helper uses localhost and port 5678; use the same port on both sides.

Give the configuration a recognizable name. Map the source folders seen by VS Code (localRoot) to the folders used by Unreal (remoteRoot). For this same-machine example, corresponding paths are the same.

Enable redirectOutput to see editor Python output in VS Code. The lesson sets justMyCode to false so library code can also be inspected. Use the launch configuration format supported by your installed debugger; the screenshots record the course's configuration.

Start and attach

In Unreal, import debugpy_unreal, then call debugpy_unreal.start(). The helper waits for the debugger, so the editor can appear frozen until VS Code attaches.

Start the saved attach configuration in VS Code and check the debugger-attached message.

Debug a script

Set breakpoints in the source file and execute that code from Unreal. The example imports debug_me and stops at its breakpoint.

Use Step Over to advance, inspect local variables and the call stack, then Continue to let the script finish. Unreal becomes responsive again when execution resumes.
