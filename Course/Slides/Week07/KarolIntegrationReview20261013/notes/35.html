Introduction to Automation Testing in Unreal Engine — REFINED

Course index · Original notes

Automated tests run repeatable checks and compare actual behavior with an expected result. They are useful for editor tools as well as engine code: a small test can catch a regression before it reaches an artist.

Choose the appropriate test

  • Unit: check a small API or isolated operation.
  • Feature: check a larger system or workflow.
  • Smoke: run a very quick basic check; the course reference specifies less than one second.
  • Stress: exercise demanding or repeated conditions.
  • Screenshot comparison: detect visual changes against a reference.

Enable the plugins

Some built-in test collections have their own plugins. For the course's Python tests, enable Python Automation Test, accept the displayed beta notice, and restart. The earlier scripting plugins remain part of the project setup.

Run and inspect tests

Open Tools → Session Frontend, select the local editor session/worker, and open Automation. Check the filters if a category appears to be missing.

Select individual tests or a category, then Start Tests. Larger selections can take time and occupy the editor. Review the results and the Automation Testing Log in Message Log; a green result alone does not explain what was exercised.

Exclude a test deliberately

Use the test's pencil control to mark it excluded and record a reason. The exclusion can be saved in configuration and affect other users or automated runs. To restore the test, clear its excluded setting.

An excluded test is skipped, not passed. The result symbol and log make that distinction visible; inspect warnings and exclusions when evaluating a run.
