Batch Importing FBX Meshes with AssetImportTask — REFINED

Course index · Original notes

Create one AssetImportTask per source file, configure shared FBX options, then submit the task collection to Asset Tools. This separates file discovery, import settings, and execution.

Discover source files

Use Path(source_folder).glob("*.fbx") to select FBX files in one folder, or rglob("*.fbx") to include subfolders. This is a glob pattern, not a regular expression. Unrelated files are excluded.

Configure each task

The important task fields are:

Field Purpose
automated Suppress interactive import prompts for batch processing.
filename Full source-file path, converted from Path to str.
destination_path Unreal content folder, such as /Game/Enviro.
destination_name Asset name, taken from the source path's stem.
replace_existing Allow replacement of existing assets.
save Save imported assets.
options Asset-type-specific import settings.

The demonstration enables replacement and saving. Inspect the import log for failures even when the task is automated.

Configure FBX and static mesh options

Create shared FbxImportUI options outside the loop. The example enables mesh and material import, disables texture import, and enables automatic type detection. Attach FbxStaticMeshImportData through static_mesh_import_data.

combine_meshes combines multiple mesh objects from an FBX into one imported mesh. The Blender examples contrast a simple mesh with a file containing several separate objects.

remove_degenerates handles degenerate geometry during import. Inspect source geometry when triangulation warnings or missing objects appear; the screenshot demonstrates a geometry problem in Blender. Degenerate triangles and non-manifold geometry are related troubleshooting topics, but are not synonymous.

Execute and inspect tasks

Use AssetToolsHelpers.get_asset_tools().import_asset_tasks(tasks). Read each task's imported_object_paths afterward to report what was imported; the call itself is shown returning None in the stub.

Construct options, then attach them to every task

This consolidated example keeps the key fields shown in the FBX screenshots. Paths are placeholders; calling the last line performs the import. The course explicitly enables replacement and saving here.

from pathlib import Path
import unreal

options = unreal.FbxImportUI()
options.set_editor_property("import_mesh", True)
options.set_editor_property("import_materials", True)
options.set_editor_property("import_textures", False)
options.set_editor_property("automated_import_should_detect_type", True)
mesh_options = options.get_editor_property("static_mesh_import_data")
mesh_options.set_editor_property("combine_meshes", True)
mesh_options.set_editor_property("remove_degenerates", True)

tasks = []
for filename in ["C:/Exports/Crate.fbx"]:
    task = unreal.AssetImportTask()
    task.set_editor_property("filename", filename)
    task.set_editor_property("destination_path", "/Game/Imported")
    task.set_editor_property("destination_name", Path(filename).stem)
    task.set_editor_property("automated", True)
    task.set_editor_property("replace_existing", True)
    task.set_editor_property("save", True)
    task.set_editor_property("options", options)
    tasks.append(task)
unreal.AssetToolsHelpers.get_asset_tools().import_asset_tasks(tasks)

static_mesh_import_data holds the nested mesh settings. If using unreal.Array.cast(unreal.AssetImportTask, tasks), use its returned array; merely calling a conversion and discarding it does not replace the Python list. Inspect each task's imported_object_paths afterward. These are the course's FBX options, not verified settings for every later engine/importer version.

Asset Tools exposes other useful operations. Check deprecation notes before reusing them: the captured open_editor_for_assets entry points to AssetEditorSubsystem as its replacement.

Python lists and Unreal arrays

A Python list works in the demonstrated call. If an API or type checker requires an explicit Unreal array, construct unreal.Array(unreal.AssetImportTask) or convert a list with unreal.Array.cast(unreal.AssetImportTask, tasks).
