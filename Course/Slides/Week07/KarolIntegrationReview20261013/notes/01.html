Initial Setup — REFINED

Course index · Original notes

Prepare an Unreal project for editor scripting and generate the Python stub used by your IDE for autocomplete. A blank project is sufficient.

Enable scripting plugins

Open Edit → Plugins → Scripting. The course enables Editor Scripting Utilities, Python Editor Script Plugin, and Sequencer Scripting. It also enables Python Foundation Packages, which supplies additional Python packages in the demonstrated engine version.

Restart Unreal after changing the plugins.

Generate the Unreal Python stub

In Edit → Project Settings, search for Python and enable Developer Mode. Restart again to generate the stub.

The generated file is <Project>/Intermediate/PythonStub/unreal.py. It describes the exposed Unreal Python API for IDE assistance. Developer Mode refreshes it on editor startup, including after changes to exposed functionality.

Next, point your IDE at the containing PythonStub folder.
