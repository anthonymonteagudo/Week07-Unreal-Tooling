Inspecting Unreal Objects with dir and help — REFINED

Course index · Original notes

Use Python introspection when a stub or documentation page does not show an inherited method clearly. Both classes and existing objects can be inspected.

List available names

dir(unreal.StaticMesh) returns available attribute names, including inherited members. Printing the entire list works but is difficult to scan.

Print one name per line instead:

for name in dir(unreal.StaticMesh):
    print(name)

The example finds get_world, which is inherited and was not listed directly on the class's documentation page.

Inspect a method

Pass the method itself to help(), without calling it:

help(unreal.StaticMesh.get_world)

The output describes the signature and return value. Here, Optional[World] means a world object or None.

help() prints its own output. The screenshot's extra print(help(...)) also prints None, the return value of help(); that wrapper is unnecessary.
