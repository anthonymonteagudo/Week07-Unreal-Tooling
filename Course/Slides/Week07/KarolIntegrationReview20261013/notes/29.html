Adding Custom Menu Actions — REFINED

Course index · Original notes

Expose frequently used scripts through Unreal menus so artists can run them without entering Python commands. This lesson adds actions to the main Edit menu and to the static mesh context menu.

Identify menus and sections

Enable Editor Preferences → General → Miscellaneous → Display UI Extension Points, then restart. The overlay shows internal section names such as EditMain, which can differ from visible labels.

Get the menu manager with unreal.ToolMenus.get(), then find a known menu such as LevelEditor.MainMenu.Edit.

The course's discovery script searches transient menu objects and collects their menu_name values. Its internal object paths are version-dependent; inspect a known object before reusing the search pattern. Lesson 31 provides the simpler ToolMenus.Edit discovery command.

Create a submenu

Find LevelEditor.MainMenu, call add_sub_menu() with owner, section, internal name, and visible label, then call refresh_all_widgets() to display the change.

Define the Python action

Subclass unreal.ToolMenuEntryScript, decorate it with @unreal.uclass(), and override execute(self, context) using @unreal.ufunction(override=True). Start with a log message to verify the action.

Instantiate the script object and call init_entry() with the target menu, section, internal entry name, label, and tooltip. Then call register_menu_entry().

Minimal action and registration

This reconstruction joins the separate definition and registration screenshots:

import unreal

@unreal.uclass()
class ExampleMenuAction(unreal.ToolMenuEntryScript):
    @unreal.ufunction(override=True)
    def execute(self, context):
        unreal.log("Menu action executed")

entry = ExampleMenuAction()
entry.init_entry(
    owner_name="KarolExample", menu="LevelEditor.MainMenu.Edit",
    section="EditMain", name="KarolExampleAction",
    label="Example Python Action", tool_tip="Run the course example")
entry.register_menu_entry()
unreal.ToolMenus.get().refresh_all_widgets()

Keep a reference to the entry in the registering module. For the later static-mesh action, create a separate entry targeting ContentBrowser.AssetContextMenu.StaticMesh and GetAssetActions. Register once per intended lifecycle; repeatedly executing registration code is not a reload-management strategy.

Click the new entry and verify its output.

Restrict an action to static meshes

Use ContentBrowser.AssetContextMenu.StaticMesh as the target menu. Initialize a separate script object and choose the appropriate section, such as GetAssetActions.

Check that the action appears and runs for static meshes, then confirm it is absent from the material context menu.

Put registration in a startup script or init_unreal.py to recreate the entries in later editor sessions.
