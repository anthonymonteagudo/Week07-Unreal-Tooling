Running Scripts From the Editor — REFINED

Course index · Original notes

Use the Output Log for interactive commands or the Tools menu to execute an existing Python file.

Import a module

Select Python in the Output Log command dropdown. Import a module from a discoverable directory, then call its functions. The example imports hello and prints its top-level message.

Execution commands behind the screenshots

In the Output Log's Python input mode, enter a quoted absolute script path, for example "C:/MyProject/Content/Python/hello.py". In Cmd mode, use py "C:/MyProject/Content/Python/hello.py". Replace the example path with your file. The menu command shown in this course is Tools → Execute Python Script; menu placement can differ between editor versions.

A module in a discoverable Python folder can instead be imported:

import hello

Import executes a module's top-level code on its first import in that interpreter session. Repeating import hello does not rerun edited code. For an intentional development reload, use import importlib; importlib.reload(hello) and account for any callbacks or other state created previously.

Execute a file from the console

In Cmd mode, the demonstrated command is py followed by the quoted script path.

The course documentation warns against using this through the editor's startup ExecCmd argument: the script may run before the editor or startup level is ready. Lesson 08 covers the dedicated startup arguments.

Execute through the Tools menu

Choose Tools → Execute Python Script, browse to the .py file, and open it. Confirm its output in the log.

Use Tools → Recent Python Scripts to run a recently executed file again.
