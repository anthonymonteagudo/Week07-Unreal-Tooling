Lab 2 • Preparation • 4 minutes • One per author

Prepare one peer test

Give each reviewer the same task and starting state. Ask for a result; let them choose the steps.

Author ____________________ Tool / version ____________________ Group ____ Letter A / B / C / D

1 User and goal Who is this for? What do they need to do, and why?
2 Task to read aloud Write one short task. Include the starting input and what must stay unchanged.
3 Success What visible result will you check?
4 Ready to repeat How will you reset? What will you show if the tool cannot run?

Example task: “Try this texture set on the target crate. Leave the protected crate unchanged.”

Ready check: prepared copies • same version • start state ready • reset ready

Choose a mode: hands-on / recording / paper or Figma. A prototype can test understanding; it cannot verify engine behavior.
