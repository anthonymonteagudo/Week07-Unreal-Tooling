Calibration example

Too vague: “The interface is confusing.”

Observed: “I selected three props. The preview did not name the targets, so I asked the author whether the light would change.”

Consequence: “I could not check the scope before committing.”

Hypothesis: “A list of affected objects may help.”

Retest: “Give a new reviewer the same three props and light. Before Apply, ask them to identify every affected object from the preview. Record whether help is needed and check all four objects afterward.”

A successful attempt is useful evidence

“The preview listed the three selected props. I checked the names and completed the task without help. Keep that preview. No failure appeared in this attempt. Next test: empty selection should create no changes and explain the next action.” Mark that next test proposed.

Conflicting reviews

If one tester succeeds and another needs help, keep both observations. Compare the version, start state, domain familiarity and assistance. Choose a retest that isolates the uncertainty. Do not average these into a numeric grade.
