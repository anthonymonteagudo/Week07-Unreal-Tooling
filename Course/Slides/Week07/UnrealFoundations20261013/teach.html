Schedule

The established class schedule remains unchanged. This deck provides extra teaching depth without treating estimated slide times as constraints. Cover familiar examples quickly, expand when students need explanation, and keep the additional slides available.

Opening

Give students the explicit three-minute project readiness activity. Check their engine version and project path. The general host check does not validate the Material/VFX fixture or the bridge receiver.

Karol-inspired sequence

Use the API documentation and generated stub together. Distinguish classes, subsystem instances and static library calls. Repeat the small-example pattern: select one input, predict the result, execute, inspect, then change one input. Connect properties to their manual controls.

Preparation

Generate stubs before class; restarting Unreal interrupts a live demonstration. Have the provided map open, the source files ready, and the expected actor and textures available. New slide examples have not been rerun in Unreal in this revision. The API snippets remain bound to the existing independent checkpoint files.

Blender transition

Complete Unreal's material and VFX workflows before the orange Blender divider. Compare Blender selection and mesh data, then demonstrate publishing through the shared bridge. This preserves a continuous Unreal introduction.
