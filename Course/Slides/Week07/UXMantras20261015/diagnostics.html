Grayscale and blur are browser display filters on an actual screenshot. The blockout is an editable CSS schematic, not a captured or implemented UI.

What survives?

In grayscale, inspect light/dark hierarchy without hue. While squinting—or using the coarse blur approximation—inspect the large masses of emphasis. In the blockout, inspect grouping, proportion, alignment and flow without wording.

What remains untested?

These checks do not establish measured text contrast, color-vision accessibility, keyboard access, comprehension or successful task completion. Return to the original, use actual controls, and observe an attempt.

Art value is perceived lightness/darkness. HSV Value is a model coordinate; it is not the same quantity as WCAG relative luminance. Equal HSV values do not guarantee equal readability.
