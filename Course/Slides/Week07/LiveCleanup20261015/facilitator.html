Facilitate Lab 1

Use the fictional renamer to establish evidence-based review before teaching UX vocabulary. Students compare a stated contract with visible behavior, then propose a test. Accept different priorities when the reasoning is supported.

Interpretation

The output violates both protected scope and the exactly-one-prefix rule. The success count alone proves neither. Internal cause, Undo, a second run and performance remain unknown.

Model finding

With only the three crates selected, I expected barrel_D to stay unchanged, but it became SM_barrel_D. This changes unrelated work.

Model retest

Restore all four starting names; select only the crates; run once; inspect all four expected names above. Then propose a separate second-run test. Do not claim that test has occurred.

Acceptable alternatives

Prioritize scope because unrelated work changes, or the duplicate prefix because it violates the naming contract. Ask for the consequence and supporting observation, not a preferred phrase.

Discussion bridge

Which preview evidence could expose the mistake before Apply? What does a success message omit? Revisit first judgments during UX, then carry input/action/evidence/protected scope into peer review.

Facilitate three-role peer reviews

Protect the 30-minute lab. Form groups of three, assign A–C, and keep tools on prepared machines. Rotate owner, tester and observer so each tool gets one observed attempt.

Time

Pairing or action

5:30–5:32

Confirm one task, prepared inputs and fallback. Assign owner, tester and observer.

5:32–5:39

Round 1: owner A, tester B, observer C.

5:39–5:46

Round 2: owner B, tester C, observer A.

5:46–5:53

Round 3: owner C, tester A, observer B.

Within each round

Reset and rotate during the last 45 seconds. No extra transition minute.

5:53–5:57

Apply the same lenses to your own tool.

5:57–6:00

Record one strength, one revision and its retest.

Evidence count

One observed attempt per tool, with two peer perspectives. Do not call this three independent reviews.

Call each 7-minute round: 0:00 state task; 0:45 attempt; 3:45 compare evidence; 5:15 keep and improve; 6:15 write the retest, reset and rotate.

Setup

Per student: one preparation page, one peer-review page and one reflection page. One Lab 1 sheet per group. Display the revised seven-minute timer. No installation during rounds.

Coach evidence

Ask what the tester expected, what happened and why it matters. Record help. A strength needs evidence too. If no fault appeared, record a useful uncertainty instead of inventing one.

Handle blockers

Allow one brief recovery attempt, then label the task blocked and use a recording or prototype. A walkthrough tests understanding; engine execution remains untested.

Attendance

Prefer triads. A fourth person can share observation. A pair alternates owner/tester and uses the remaining round for a retest. Record the actual people and attempts; do not inflate coverage.

Protect the close

End concepts at 5:30. Protect the 5:53 self review and 5:57 revision. If late, state the reduced attempt time honestly. The Lab 1 investigation runs 5:10–5:18 within the UI/UX block.
