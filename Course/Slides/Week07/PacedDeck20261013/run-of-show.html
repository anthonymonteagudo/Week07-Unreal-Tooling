Density findings and changes

Opening/Python: too dense previously. The 21-slide opening included setup, multiple object/path explanations, raw API detail, two demo sequences and a Blueprint tie-in in 32 minutes. It now has 11 live slides. Required object distinctions and paths move into the diagram and handoff notes. The two seven-minute demo slots remain visible in the run of show.

UX: still brisk, but reduced. The previous 18-slide block now has 13 live slides, including a short section divider and four minutes of task writing. Use the read-aloud notes selectively: one example per principle, one response to a prediction, and a two-minute open-question window. Do not read every source insight aloud. The GDC examples illustrate mental models and iteration; they are not full talk summaries.

Peer testing: no spare installation time. The 35-minute block is exactly 3 minutes briefing + 30 minutes attempts/reviews + 2 minutes switching. Use the author’s machine. A tool that cannot launch promptly uses its declared prototype/recording fallback. Record the actual review mode.

Assessment: keep the reveal concealed. Hold the prediction slide for the full working period. Do not advance to the answer until groups have recorded their own result and trust judgment.
