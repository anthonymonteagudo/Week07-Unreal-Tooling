Updating Deprecated Editor Subsystem Access — REFINED

Course index · Original notes

The course began against Unreal 5.1 and records a change around 5.3: retrieve an editor subsystem from the running editor instead of constructing it directly.

Historical form shown in the source:

import unreal
editor = unreal.EditorActorSubsystem()

Use the subsystem accessor in the updated example:

import unreal
editor = unreal.get_editor_subsystem(unreal.EditorActorSubsystem)
actors = editor.get_selected_level_actors()

unreal.EditorActorSubsystem is the class passed to the accessor; editor is the returned editor-managed instance. This is a specific migration note, not a claim that every constructor in Unreal is deprecated.

When following older screenshots, check the API reference/stub for the engine version actually in use. Keep the algorithm and update the obsolete access pattern. The source notes that the accessor was also available in some earlier versions. No images were supplied for this lesson.

This course development started when Unreal 5.1 was the latest.

Half a year later, 5.3 is around and for sure there will be even more releases.

Keeping videos up to date is very difficult. Each time I notice something deprecated I do my best to update them in some way.

I also understand that games are not always made on the latest release of engine and that updating it may be difficult in case of big projects.

I will keep extending list of deprecations and differences between various UE 5.3 versions and hopefully, it will help you if you struggle with errors while following tutorials included in the course.

Editor subsystems creation is deprecated and will be removed in UE5.3.

Unreal < 5.3 syntax:

  1. EditorActorSubsystem = unreal.EditorActorSubsystem()

Unreal 5.3+ syntax:

  1. EditorActorSubsystem = unreal.get_editor_subsystem(unreal.EditorActorSubsystem)

It also is available in some older releases so you can start updating your tools even before moving to 5.3
