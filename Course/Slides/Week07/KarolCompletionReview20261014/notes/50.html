Working with Unreal Arrays Maps and Structs — REFINED

Course index · Original notes

Unreal exposes typed containers and structs to Python. They often support familiar iteration and inspection, but they are not interchangeable with arbitrary Python lists/dictionaries at every reflected API or Blueprint boundary.

Inspect and iterate returned arrays

import unreal
asset_paths = unreal.EditorAssetLibrary.list_assets("/Game/StarterContent/Textures/")
for path in asset_paths:
    print(path)

The folder is the course example and must exist in the project. The console's direct object representation can show an Unreal type/reference while print(...) or iteration shows values; that display difference does not mean the array is empty.

Use dir(asset_paths) or help(...) to inspect available operations. The screenshot includes familiar methods such as append, count, insert, reverse and sort. Convert with list(asset_paths) when you deliberately need a Python list; iteration alone does not require conversion.

Cast a Python list with an explicit element type

The failed constructor attempts pass values where Unreal expects type information. Use the cast helper and keep its returned value:

numbers = unreal.Array.cast(int, [1, 2, 3])
print(list(numbers))

Do not copy the failing unreal.Array([1, 2, 3]) or unreal.Array(1, 2, 3) attempts. The declared element type constrains the array; do not rely on it accepting an arbitrary mixture of strings and integers.

Pass a typed map through a Blueprint Python node

This example converts string keys and integer values:

import unreal
my_dict = {"a": 1, "b": 2}
unreal_map = unreal.Map.cast(str, int, my_dict)

For inspection in Python, dict(unreal_map) produces a normal dictionary.

On Execute Python Script, add an output named unreal_map. The assignment above supplies that output; the node's separate Return Value reports execution success, not the map data.

Create a Blueprint variable named Config, change its container to Map, and set its key/value types to String → Integer. Connect the node's unreal_map output to Set Config, including the execution wire. The receiving Blueprint type must match the Python-created map; context-sensitive suggestions alone may not infer it.

This conversion addresses the demonstrated typed boundary. It does not prove every API needs an explicit cast: some APIs accept compatible Python sequences. Remote Control also needs a correctly exposed signature and serializable result; compare lesson 44's JSON-string alternative.

Construct structs with named fields

The example uses MaterialParameterInfo. Inspect its fields and the MaterialParameterAssociation enum rather than guessing an integer enum value.

import unreal
info = unreal.MaterialParameterInfo(
    association=unreal.MaterialParameterAssociation.GLOBAL_PARAMETER,
    index=-1,
    name="test_name",
)
print(info)

Here name identifies the parameter, association selects a global parameter rather than a layer/blend parameter, and index=-1 is the demonstrated global-parameter value. This constructs identifying data; it does not create a material parameter or set its value. Use the appropriate material API for the actual operation.
