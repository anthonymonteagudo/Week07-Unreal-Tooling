Read aloud

This square is a schematic, not the exhibit UV layout. Hold world area and texture resolution fixed. Doubling both UV dimensions quadruples UV area. The square root in the density formula turns that fourfold area ratio into twice the linear pixel density. The course scale is target density divided by current density. Autodesk documents the UV scale controls, while this relationship follows from the supplied density_math.py formula.

Concept sources

Autodesk: UV scale controls: scaleU and scaleV act on UV coordinates around a pivot. The density ratio is derived from the course math, not prescribed by this API page.
