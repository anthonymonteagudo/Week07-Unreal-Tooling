Read aloud

The opening call begins a group of undoable scene commands. The closing call ends it. One later Undo reverses the group. The next slide shows finally so the close call still runs on an exception. Closing a chunk is cleanup, not automatic rollback. Run the actual Step 06 example and inspect all three changed attributes before Undo.
