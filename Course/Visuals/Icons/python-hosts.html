Teaching placement

  • Introduce all three on the Python Hosts slide. On subsequent demonstration slides, put one small badge beside the launch instruction.
  • Your current first Python run uses mayapy, so use the external-Python badge even though that code also works with ordinary Python.
  • In VS Code, show badges in rendered stage READMEs. Keep Python file headers plain, executable-safe comments such as “RUN: VS Code terminal with mayapy.exe.” PNGs do not automatically change VS Code’s file icons or interpreter indicator.
  • Keep external Python separate from Python running in the open Maya application. Choosing mayapy in VS Code is not a connection to the interactive scene.
