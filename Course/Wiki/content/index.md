## Start with the current work

**Week 2 connects asset data to an observable result.** Begin with [Game Assets, Pipelines, and Validation](week02.html), then use the [museum investigation guide](museum-lab.html) during the lab. The [exhibit guide](exhibit.html) helps you turn a small technical relationship into something a visitor can understand.

You can contribute a useful question before you know the answer. Describe what should happen, what you actually observe, and what evidence could distinguish the possible causes.

## Find the mechanism

- A surface looks different: [materials and shaders](materials.html), [normals](normals.html), [color and numerical data](textures.html).
- A pattern is mirrored or stretched: [UVs and texture lookup](uvs.html).
- An import differs from Maya: [DCC-to-Unreal handoffs](handoff.html).
- An object bends incorrectly: [skeletal assets](skeletal.html).
- An object changes with distance: [mips, mesh LOD, and streaming](representations.html).
- A fix is hard to explain or reproduce: [validation](validation.html) and [technical documentation](documentation.html).

## Learn at two depths

The main explanation and inspection prompts establish the shared foundation. “Explore further” links open the mathematical, rendering, or implementation detail when you are ready. You do not need to finish every linked resource before using the lab guide.

Start with the [glossary](glossary.html) when a term is unfamiliar, or use the [reading and visual library](resources.html) to choose a focused next resource.
