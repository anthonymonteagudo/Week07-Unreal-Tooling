  • LlamaIndex: document processing/retrieval for AI applications; possible documentation-assistant exploration with separate data/dependency considerations. https://github.com/run-llama/llama_index
  • Robyn: async Python web framework with Rust runtime; possible pipeline service/backend. Repository redirects to https://github.com/sparckles/Robyn
  • DuckDB: in-process analytical SQL database; query tabular asset reports locally. https://github.com/duckdb/duckdb
