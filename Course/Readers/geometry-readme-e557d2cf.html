EX20 editable geometry sources

The build extracts the existing museum's 01_synthetic_flipped_normals and 04_synthetic_open_boundary source meshes. It saves both extracted Incorrect and locally repaired Correct OBJ files beside this document. These are the existing diagnostic objects, with their 200 cm dimensions and pivot retained. JSON snapshots preserve explicit vertex IDs, triangle IDs and per-corner UVs.

The original imported meshes point at an unavailable D:/Personal Projects/... FBX location. No files at that location are edited. For a student repair, import the supplied Incorrect OBJ into Maya and export a new FBX. Use Reimport With New File on the sandbox Incorrect asset to select that FBX, rather than using its inherited legacy import filename. Preserve material slot count and assign the sandbox M_EX20_OneSidedNeutral material after reimport if required.

Coordinates are centimeters with Z up, matching the source in Unreal. Configure Maya for centimeters and Z up before importing, or make an explicit equivalent axis conversion and reverse that conversion on export. Keep the pivot at the origin and object scale at one. The source's imported UVs are all (0,0); this is an untextured topology exercise, so UV authoring is not an additional fault.

Pair Incorrect Exact repair Technical verification
ReversedFace One +Y face has reversed winding; two triangles (source IDs 2 and 3). Reverse only that face's winding and normals. 12 triangles before and after; 8 geometric vertices; zero border/nonmanifold edges; consistent winding.
OpenBoundary The -X quad face is absent. Fill the single planar four-edge boundary, with winding consistent with neighboring faces. 10 triangles becomes 12; 8 geometric vertices; four border edges becomes zero; no change to bounds.

Both sandbox variants disable Nanite and use the same opaque, one-sided neutral material. This keeps missing/backfacing polygons inspectable with standard triangle rendering. The shared rendering changes are controls, rather than additional Incorrect faults. Review the fault from the front of each grid bay, then orbit to distinguish a backface from an absent polygon.

The OBJ and topology checks are generated/verified by the headless build. A Maya import/export/reimport round trip has not been executed in this task.
