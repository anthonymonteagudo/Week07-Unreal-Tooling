Start with the current work

Week 2 connects asset data to an observable result. Begin with Game Assets, Pipelines, and Validation, then use the museum investigation guide during the lab. The exhibit guide helps you turn a small technical relationship into something a visitor can understand.

Find the mechanism

  • A surface looks different: materials and shaders, normals, color and numerical data.
  • A pattern is mirrored or stretched: UVs and texture lookup.
  • An import differs from Maya: DCC-to-Unreal handoffs.
  • An object bends incorrectly: skeletal assets.
  • An object changes with distance: mips, mesh LOD, and streaming.
  • A fix is hard to explain or reproduce: validation and technical documentation.

Learn at two depths

The main explanation and inspection prompts establish the shared foundation. “Explore further” links open the mathematical, rendering, or implementation detail when you are ready. You do not need to finish every linked resource before using the lab guide.

Start with the glossary when a term is unfamiliar, or use the reading and visual library to choose a focused next resource.
