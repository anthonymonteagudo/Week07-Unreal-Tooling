Week 5: Applied math for Technical Artists

Status update: The later instructor-confirmed 180-minute outline supersedes this initial scope proposal. Use the expanded slide review and its source-context guide. Euler angles, quaternions, interpolation, and all named coordinate spaces remain live; the earlier reduction to 24 live slides is withdrawn. The corrections below remain useful historical reference.

Instructor working brief, 26 September 2026. Based on the supplied January 2022 notes and the current Week 5 wiki outline. This is a proposed teaching route, not an edited PowerPoint or an approved assignment. The current Week 5 deck and intended student project still need identification.

Teaching focus

Use one visible operation throughout the lecture: place an object relative to another object, compute the direction between them, and use that direction to control an observable result. Establish the coordinate frame and expected result before introducing the formula. Connect this to the normal-direction and UV-coordinate examples from Week 2.

The source spans several older lectures. It is reference material, not evidence that every topic belongs in one Week 5 session. Keep vector operations, trigonometry, and the transformations needed by the actual demo in the live lesson. Treat a full camera/projection pipeline and hand-written matrix inversion as proposed optional depth unless the student project requires them.

Corrections before reuse

Source wording or issue Replacement for teaching
Slope formula uses ambiguous superscripts and parentheses m = (y₂ − y₁) / (x₂ − x₁). A vertical line has undefined slope. A horizontal line has slope zero.
“Two equal sides at 45 degrees” An isosceles right triangle has two 45° angles. Isosceles triangles in general do not.
“sin2 + cos2 = 1” sin²(θ) + cos²(θ) = 1. Both terms use the same angle.
Inverse trig is rarely used because it is complicated Inverse trig recovers angles from ratios. Introduce atan2(y, x) for a planar direction and acos for the angle between nonzero vectors. Use the actual project's coordinate and angle conventions.
“Law of Sin: sin a + sin b = sin c” a / sin(A) = b / sin(B) = c / sin(C), with each side opposite its corresponding angle.
Incomplete law of cosines a² = b² + c² − 2bc cos(A), where A is the included angle opposite side a.
“All vectors originate from the origin” A displacement vector has magnitude and direction and can be drawn at any location. A position vector represents a point relative to a chosen origin.
“All parallel vectors are vectors plus offset vectors” Nonzero parallel vectors are scalar multiples of one another. Moving an arrow's drawing does not change its displacement vector.
Missing square root in vector length ‖v‖ = √(vₓ² + vᵧ² + v_z²). For points A and B, distance is ‖B − A‖.
Ambiguous normalization notation v̂ = v / ‖v‖, for nonzero v. The project must define what happens when the length is zero or too small.
Dot product is “Always a floating point value!!” The dot product produces a scalar. Its programming type depends on the inputs and implementation.
Dot product described as associative Dot products are not generally associative. Use scalar compatibility: (k a) · b = k(a · b) = a · (k b).
Angle between vectors cos(θ) = (a · b) / (‖a‖ ‖b‖) for nonzero vectors. Clamp a computed cosine to [−1, 1] before acos to handle rounding.
Zero vector described as perpendicular Its dot product with every vector is zero, but an angle involving the zero vector is undefined.
Cross product notation uses ordinary multiplication Use a × b. The familiar 3D cross product is perpendicular to both inputs when nonzero. Parallel inputs produce zero. Order changes its sign.
A matrix is an N-dimensional array A matrix is a rectangular array with rows and columns. Higher-dimensional arrays require a broader description.
w = 0 means orientation In the affine point/direction use here, w = 0 represents a direction and w = 1 a point. An orientation is not fully described by a single direction.
Pre/post multiplication universally determines local/global space Declare row or column vectors, which side the matrix acts on, and what the matrix maps between. Then derive composition order. Memory storage order is a separate choice.
Object space is usually identity Local coordinates exist relative to an object's frame. Its local-to-world matrix can be nonidentity. Identity is a useful starting case, not a general transform rule.
Projection simply flattens points Projection produces clip coordinates. Perspective division by w produces normalized device coordinates; the viewport mapping follows. Preserve depth for visibility.

Use one stated convention for worked examples. For column vectors, p_world = T R S p_local applies scale, then rotation, then translation. A pure direction with w = 0 receives no translation. Avoid transferring that expression verbatim into a different library convention.

Sample read-aloud narration

“We have two positions in the same coordinate frame. Subtract the starting position from the destination. That gives us the displacement: how far to move along each axis. Here the displacement is three units in X and four in Y, so its length is five. If we normalize it, we keep the direction and make its length one. We can then choose a movement distance separately. What do you predict will happen if the two positions are identical? What part of that distinction would you like us to revisit?”

Instructor facilitation

Reserve a short prediction pause before each visible result and a separate opportunity for student questions after normalization and transforms. Adjust the number of worked examples to the actual class duration; protect time for students to inspect and test the project. Keep expected answers and preparation directions out of the spoken notes.

Explore further: Camera and projection spaces

Entry question: How does a world-space point reach a screen location? Trace local coordinates through world, view, clip, normalized device, and viewport coordinates. Introduce the inverse camera world transform after students understand changing coordinate frames. Return to the live lesson's point/direction distinction. This is proposed appendix content, not a current linked appendix in the deck.
