Tech Art Museum — Interactable Exhibit Migration

Audit source: /Game/TechArtMuseum/Maps/TechArtGallery_Interactive in TechArtMuseumIntegration.

The level scan found 530 actors and 12 explicit technical-exhibit headings. This document covers those curriculum exhibits, not the surrounding portfolio paintings, Megascans, furnishings, or decorative props.

What can be converted now

BP_MuseumExhibitItem_Test inherits the working Coreblazer static-item interaction. It is suitable for one static mesh whose appearance is stored on the mesh asset itself.

Do not mass-replace the displays until these capability gaps are handled:

  1. Material overrides: the painting exhibits all reuse /Game/Showcase/Meshes/SM_Painting_01a with different material overrides. The current inspection item carries ItemMesh, but not the source component's override materials. Add an Inspection Materials array and apply it to BP_InspectItem after Set Static Mesh.
  2. Stable Learn More identity: MuseumExhibitWeb currently finds the source item by comparing mesh assets. Shared painting meshes can therefore resolve to the wrong URL. Pass/store the interacted source actor (or a stable exhibit ID) when inspection begins and resolve the URL from that actor.
  3. Skeletal inspection: Animation and Morph Targets require a skeletal-mesh inspection actor that copies skeletal mesh, animation/AnimBP, playback rate, looping, morph values, materials, and inspection transform. The present static S_Item.ItemMesh path cannot preserve these exhibits.
  4. Composite inspection: Z-fighting requires both overlapping cubes, and some lessons are clearer as grouped comparisons. A composite inspector must copy multiple mesh components, transforms, and materials.
  5. Interaction bounds: bounds should be configured independently from visual scale. Do not scale a sphere collision with the exhibit actor and accidentally multiply its effective range.

Recommended implementation order

Priority Work Result
P0 Add material overrides and direct source-actor/Exhibit ID handoff Makes all shared-painting panels safe and gives every item the correct Learn More URL
P1 Convert the seven single-mesh Broken Geometry objects and four Bricks objects Exercises the existing static pipeline with the least architectural risk
P2 Convert Alpha Leaf, Cat, Piet, Gris, Grid, Glitch, Grow, and Line Requires the P0 material-copy work
P3 Add skeletal inspector; convert Animation and Morph Targets Preserves motion, skinning, animation settings, and morph deformation
P4 Add composite inspector; convert Z-fighting and optional grouped comparisons Preserves demonstrations that depend on multiple objects

Exhibit manifest and educational copy

EX01 — Alpha Leaf

Scene targets

  • SM_Painting_01a4 — material /Game/Showcase/MuseumExhibits/01_leaf/01_leaf_02_Mat.01_leaf_02_Mat
  • SM_Painting_01a6 — material /Game/Showcase/MuseumExhibits/01_leaf/01_leaf_01_Mat.01_leaf_01_Mat

Learning objective: Explain how an opacity mask turns a rectangular polygon into a foliage silhouette, and why threshold choice, texture filtering, mipmaps, and blend mode affect edge quality and cost.

CORRECT version: Masked material with intentional clip threshold, useful mip behavior, two-sided/normals settings chosen deliberately, and minimal transparent overdraw.

INCORRECT version: Opaque card or poorly tuned translucent/masked edge that produces a visible rectangle, halos, crawling edges, or unnecessary overdraw.

Popup copy: “The leaf is still rendered on simple geometry; its silhouette comes from texture data. A production-ready masked material balances clean edges against shimmer and overdraw, especially as the card becomes small on screen.”

EX02 — Cat

Scene target: SM_Painting_01a2 — material /Game/Showcase/MuseumExhibits/02_cat/02_cat_01_Mat.02_cat_01_Mat

Learning objective: Read a stylized image material as layered UV-space shapes and masks, then understand how coordinate transforms and operation order control the final composition.

CORRECT version: Shapes remain aligned and stable because UV normalization, aspect correction, mask composition, and color layering occur in the intended order.

INCORRECT version to add: Break aspect correction or mask ordering so shapes stretch, drift, or overwrite one another.

Popup copy: “Complex-looking graphics can be assembled from simple masks. The important technical-art skill is controlling coordinate space and the order in which masks are combined.”

EX03 — Piet

Scene target: SM_Painting_01a9 — material /Game/Showcase/MuseumExhibits/03_mondriaan/03_PietMondriaan_01_Mat.03_PietMondriaan_01_Mat

Learning objective: Build crisp procedural color regions from UV coordinates and understand why normalized coordinates and aspect ratio matter.

CORRECT version: Stable, intentional divisions with aspect-correct line widths and predictable color masks.

INCORRECT version to add: Use uncorrected UVs or overlapping thresholds, producing stretched lines, gaps, or order-dependent color errors.

Popup copy: “This composition is a useful UV-space exercise: coordinates become masks, masks become regions, and regions select colors. Small math errors show up immediately as uneven lines or leaking blocks.”

EX04 — Gris

Scene target: SM_Painting_01a11 — material /Game/Showcase/MuseumExhibits/04_gris/04_gris_01_Mat.04_gris_01_Mat

Learning objective: Show how a material reduces or remaps color while preserving readable value structure.

CORRECT version: Uses a deliberate luminance/remap method and maintains useful contrast.

INCORRECT version to add: Naively averages channels or crushes the range, making equally bright colors separate incorrectly or losing detail.

Popup copy: “Grayscale is not simply ‘remove color.’ Channel weighting and range remapping determine whether the image keeps the same visual hierarchy after chroma is removed.”

EX05 — Grid

Scene target: SM_Painting_01a10 — material /Game/Showcase/MuseumExhibits/05_grid/05_grid_01_Mat.05_grid_01_Mat

Learning objective: Generate a procedural grid and make its line width stable under scaling and distance.

CORRECT version: Uses fractional coordinates plus derivative-aware filtering or smooth transitions to reduce shimmer.

INCORRECT version to add: Hard thresholds without filtering, causing aliasing, moiré, and unstable line thickness.

Popup copy: “A grid is simple mathematically but difficult visually. Screen-space derivatives let the shader soften lines only as much as needed, keeping the pattern readable without excessive shimmer.”

EX06 — Glitch

Scene targets

  • SM_Painting_01a15 — material /Game/Showcase/MuseumExhibits/07_glitch/07_glitch_01_Mat.07_glitch_01_Mat
  • SM_Painting_01a13 — material /Game/Showcase/MuseumExhibits/07_glitch/07_glitch_02_Mat.07_glitch_02_Mat

Learning objective: Decompose a glitch effect into time, band masks, quantized offsets, channel separation, and bounded noise.

CORRECT version: Controlled, art-directable distortion that remains inside known sampling and performance limits.

INCORRECT version to add: Unbounded or per-pixel-random offsets that flicker incoherently, sample outside valid regions, or cost far more than the visible result warrants.

Popup copy: “Convincing glitches are structured rather than purely random. Time is quantized, bands select affected regions, and offsets are bounded so the effect remains readable and controllable.”

EX10 — Grow

Scene target: SM_Painting_01a16 — material /Game/Showcase/MuseumExhibits/10_grow/10_grow_01_Mat.10_grow_01_Mat

Learning objective: Connect a growth mask to reveal, displacement, timing, normals, and mesh bounds.

CORRECT version: A coherent mask drives reveal/displacement with adequate tessellation or vertex density, corrected bounds, and believable surface response.

INCORRECT version to add: Displacement clips outside bounds, tears across sparse topology, or reveals color without matching geometry/normal changes.

Popup copy: “Growth effects usually coordinate several systems: a moving mask, vertex displacement, surface shading, and bounds. If those systems disagree, the effect clips, pops, or looks detached from the object.”

Learning objective: Diagnose animation failure by separating deformation data, animation data, playback configuration, and component animation mode.

CORRECT popup: “The reference run combines a compatible skeleton, intentional skin weights, valid animation keys, and the correct component playback mode. Each layer must agree for motion to read properly.”

Animation-mode popup: “A Skeletal Mesh Component can use an Animation Blueprint or play a specific asset. Choosing the wrong mode prevents the expected animation source from driving the pose.”

EX21 — Morph Targets

Scene targets: SK_MorphCube_Correct and SK_MorphCube_Incorrect.

The integrated project currently contains the actors and labels but the audit could not resolve their skeletal mesh assets. The corresponding assets exist in TechArtMuseumAuthor under:

  • /Game/Showcase/MuseumExhibits/new/AnimatedMorphCube/Correct/SK_MorphCube_Correct.SK_MorphCube_Correct
  • /Game/Showcase/MuseumExhibits/new/AnimatedMorphCube/Incorrect/SK_MorphCube_Incorrect.SK_MorphCube_Incorrect
  • /Game/Showcase/MuseumExhibits/new/AnimatedMorphCube/Shared/SK_MorphCube_Correct_Anim.SK_MorphCube_Correct_Anim

Port those dependency-closed assets before converting the exhibit.

Learning objective: Explain that morph targets require identical vertex identity/order between base and target shapes, plus valid animation curves or explicit morph weights.

CORRECT popup: “A morph target stores a position delta for each corresponding vertex. When base and target topology agree, the same weight produces a stable, intentional deformation.”

INCORRECT popup: “Changed topology, mismatched vertex order, or unintended deltas make vertices move toward the wrong destinations. Material or normal issues can further expose the failure.”

Definition of done for every replacement

  • The original display transform and visible material(s) match before interaction.
  • Entering and leaving the interaction zone shows/hides one prompt reliably.
  • Inspection title and description match this manifest; no placeholder “Exhibit A” text remains.
  • The inspected object is framed at a readable scale and rotates without clipping.
  • CORRECT/INCORRECT status is explicit in both plaque and popup where applicable.
  • Learn More appears only when that exact exhibit has an approved valid URL, and opens the expected destination.
  • Static material overrides, skeletal animation/morph state, or composite components survive the transition into inspection.
  • The original display is restored exactly once when inspection ends.
