Rebuild

Python with Pillow and Node.js with marked are required. From this folder:

python Source/review_data.py
python Source/technical_examples.py
node Source/build.mjs
node ../../../Tools/build_readers.mjs
python Source/verify_review.py

If marked is not on the Node resolution path, set COURSE_NODE_MODULES to a local node_modules directory containing it. The build script also recognizes this workstation's bundled dependency path. No remote scripts are run by this build.

Source/review_data.py contains the manually authored findings and detailed proposals. Source/build.mjs, review.css, and review.js produce the review layout and controls. current_slides.json stores current editable text, tables, notes, and media relationships. Source/technical_examples.py contains checked arithmetic and illustrative validation examples, with no Maya or Unreal edits.

Source/discussion_data.py contains the participation points by current slide number, and Source/discussion_intro.md contains their teaching and time-allocation guidance. The build produces DISCUSSION_PLAN.md from those sources. Edit the sources rather than the generated plan.

Build the visual library first if its manifest is missing. The shared reader builder formats prepared Markdown/CSV and rewrites local document links to those views. It preserves original source documents and does not fetch external websites. The reader pages retain source paths and modification times so older review numbering is not confused with this deck.

Source/extract_deck.py records the supplied deck's source path and hash and refuses to overwrite a differing snapshot. Do not re-extract from a revised deck while retaining these findings or images. Start a new dated review or deliberately remap every slide identity. Source/CurrentSlides contains native PowerPoint exports at 1280×720, and Source/ContactSheets contains inspection sheets. Regenerate images through PowerPoint when reviewing a different snapshot.
