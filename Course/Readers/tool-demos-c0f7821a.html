Launch in Maya

Use a centimeter scene. Paste into the Python tab of Maya's Script Editor:

import sys
tools_root = r"D:\Personal Projects\Maya\Tools"
if tools_root not in sys.path:
    sys.path.insert(0, tools_root)
from lesson_materials.week_05_applied_math import show
show()

Build the locator sandbox or the FK/IK arm. Each build adds a unique fixture without replacing the scene. Select the points/controls with the buttons and manipulate them in Maya. Undo removes the latest build. Reopen the UI and build a fresh fixture if you need to recover its controls; saved scenes retain the native math graph.
