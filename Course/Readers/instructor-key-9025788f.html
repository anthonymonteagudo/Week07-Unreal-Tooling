Sandbox Grid — Instructor Answer Key

Instructor-only. This document reveals every fault and repair. Keep it separate from student observation prompts.

The saved map contains 12 controlled pairs. Asset authoring succeeded; fresh-load validation, live rendering and the limited Play probe are pending at this revision. A configured pair is not a claim that its visual symptom or physical input has been tested.

For every repair: keep Correct as the reference; change the authoritative Incorrect source/property; preserve the pair's unrelated geometry, materials, scale, lighting and playback. Re-run the technical check and the visible comparison. The builder intentionally restores the authored defects on rerun.

The front-facing gold-zone R answer actors show a concise fault/fix. This document adds the full verification and source limits. E inspection is an entry smoke test; exhibit pairs use observation-only presentation actors.

01 — EXLOD: LOD generation and distance switching

Bay origin: (0, 0, 0) cm. Camera: CAM_EXLOD_Near.

Objective: Relate projected size to LOD choice, triangle cost, and silhouette preservation.

Student observation cue: Walk backward through the marked views. Compare the silhouettes and the triangle evidence.

Break: Duplicate Correct, then remove LOD1 and LOD2 from the duplicate. Keep LOD0, materials, collision, display scale and Nanite state matched.

Actual Incorrect contract: Incorrect is missing LOD1 and LOD2; its dense LOD0 remains active at every distance.

Intended fix: Open SM_InductionCoil_LOD_Incorrect. Generate LOD1 at 35% and LOD2 at 10%; disable Auto Compute LOD Screen Size and set 1.00 / 0.50 / 0.30. Keep Nanite disabled. After rebuilding, copy Correct bounds extensions to retain matched teaching bounds.

Verify: Confirm three descending render triangle counts and matched LOD0/materials/collision, then check silhouette and transitions at near, mid, and far marks using LOD Coloration or the Static Mesh Editor LOD picker.

Evidence and limits: Correct render triangle counts: 150,000 / 52,500 / 15,000; Incorrect: 150,000 only. Fresh-load validation confirms screen thresholds 1.00 / 0.50 / 0.30 and reduction fractions 1.0 / 0.35 / 0.10. Automatic rendered switching remains a separate review gate. Both copies disable Nanite to make the conventional-chain defect observable. Rear forced-LOD witnesses are labeled separately from the automatic main specimens. Bounds extensions are normalized on both copies to keep teaching bounds matched.

08 — EX23: Color and numeric texture data

Bay origin: (2200, 5600, 0) cm. Camera: CAM_EX23_Near.

Objective: Distinguish display color from numeric roughness/metallic data.

Student observation cue: Compare the lamp metal response under the same light. Trace G to roughness and B to metallic.

Break: Duplicate the linear packed texture, enable sRGB and use its compile-consistent Color sampler. Do not alter G/B channel wiring or compression.

Actual Incorrect contract: Packed numeric data is marked sRGB. Both textures use identical TC_DEFAULT compression; no channel swaps.

Intended fix: Disable sRGB on T_EX23_Data_Incorrect_sRGB. Change that material texture sampler to Linear Color to keep sampler validation consistent with the repaired texture.

Verify: Correct and repaired roughness/metallic responses match. Packed map sRGB=False; G->Roughness and B->Metallic; Base Color remains sRGB.

Evidence and limits: G feeds Roughness and B feeds Metallic on both. Base Color stays sRGB. Both packed textures use TC_DEFAULT. Color versus Linear Color sampler type follows the texture classification for valid compilation; it is not a second independently introduced visual fault. The older prototype also changed compression, so its one-setting claim was not accepted.
