Museum Repair Lab 2 — Instructor Setup and Break/Fix Guide

Outcome

Lab 2 now uses a fork of the integrated museum prototype. Students compare visible Correct and Incorrect evidence, identify the owning pipeline stage, repair what they can, and document the diagnosis. The separate Western environment remains optional and is not part of this lab path.

Lecture-aligned minimum viable scope

The current Week 2 deck establishes the teaching sequence: asset data, handoffs, observation before diagnosis, metadata, textures, materials, skeletal assets, and documentation. The fastest shippable lab is therefore five stations, in this order:

  1. Normals and shading — EX24/EX20. Directly reinforces the Normals, Observation before Diagnosis, and Museum Guide: Geometry and Shading slides.
  2. RGB, sRGB, and numeric texture data — EX23. Directly reinforces Anatomy of a Texture Asset, Compression Changes Data, and Texture Triage.
  3. Materials across Maya and Unreal — EXMAT. Directly reinforces Maya to Unreal: Minimum Viable Handoff, Anatomy of Material, Material Graph → Material Instances, and Material Triage.
  4. LODs — EXLOD. This is core lab content, not a bonus. It reinforces LODs, LOD Selection and Generation, and the final collision/LOD museum guide.
  5. UV sampling and texel density — EX29. Reinforces the UV-layout, texel-density, mip, and texture-triage material.

If class time remains, add geometry integrity, mips/compression, and the existing skeletal comparison as instructor-led extensions. Niagara and VAT remain Advanced media/reference paths until a project-authored pair is validated; do not let them block the five-station lab.

The revised slide deck uses draft visual tags:

  • LAB — directly supports observation or repair in the museum;
  • ADVANCED — valuable extension, not required for the core repair;
  • SUPPLEMENTAL — optional exploration or external reference.

These labels are intentionally easy to rename when the final category vocabulary is chosen.

Build and reset

Create the fork once with:

UnrealEditor-Cmd.exe TechArtMuseumIntegration.uproject -run=pythonscript -script=Scripts/PrepareMuseumRepairFork.py -unattended -nop4 -nullrhi -DDC-ForceMemoryCache

The script refuses to overwrite an existing map. It also adds/configures the proven interaction smoke test and reconnects copied TextureCoordinate, Morph Cube, and animation display actors to their local assets. To reset a class copy safely, duplicate L_MuseumRepair_CleanReference in the Unreal Content Browser and assign the duplicate to that group. Never reset from the student's modified map.

Validate all maps and required sources with Scripts/ValidateMuseumRepairReadiness.py. Its machine-readable report is written to Saved/MuseumRepairReadiness.json.

Path of least resistance for the first class run

  1. Duplicate L_MuseumRepair_Student once per group.
  2. Assign only EX24, EX23, EXMAT, EXLOD, and EX29.
  3. Keep the original museum displays visible; add interaction only when it preserves the evidence faithfully.
  4. Use the existing Correct specimen as the control and edit only the Incorrect duplicate.
  5. If a repair requires Maya or unsupported interaction, accept an exact diagnosis plus authoritative repair procedure.
  6. Run the functional interaction smoke test before distributing each group map.

This avoids new player-controller work, a second environment, skeletal-inspector dependencies, and a Niagara/VAT pipeline on the critical path.

Class workflow

Lab 1 — observe only

  1. Give students 5–10 minutes to walk through independently.
  2. For each exhibit, record the neutral symptom, two pieces of evidence, likely owning stage, and a confirming test.
  3. Do not repair exhibits during Lab 1.
  4. Walk through the exhibits as a class.
  5. Show the Lab 1 answer key at the end of Week 2.

Lab 2 — group repair

  1. Duplicate the Student map once per group or give each group an isolated branch/workspace.
  2. Let groups choose bugs and order freely.
  3. Correct references are visible but locked. Incorrect specimens are editable.
  4. A group may submit a precise diagnosis and repair plan for an asset it cannot technically repair.

Station contract

Each finished station must provide:

  • one visible Correct reference and one editable Incorrect specimen;
  • the same camera, light, transform context, and relevant material inputs;
  • a neutral plaque that does not disclose the root cause;
  • an interaction popup with title, observation prompt, production consequence, and optional Learn More link;
  • a stable exhibit ID and pair ID;
  • an instructor key outside the student-facing map;
  • a clean reset source;
  • verification of at least one unrelated property.

Use MUSEUM_LAB02_EXHIBIT_MANIFEST.csv as the integration queue. READY means both teaching states already exist. SOURCE_READY means the source is imported and only the controlled duplicate/fault must be authored. READY_DISPLAY_ONLY means the assets exist but require the planned skeletal inspector for full inspection mode. STAGED_NOT_AUTHORED and CONCEPT_ONLY must not be advertised as finished exhibits.

Required station recipes

EX23 — RGB and sRGB

Break: Duplicate the correct numeric-data texture/material. Enable sRGB or route a color-decoded channel into Roughness/Metallic. Keep the source pixels and light identical.

Fix: Treat numeric masks as linear data, restore the documented channel and sampler, and leave Base Color textures in sRGB.

Verify: Correct, repaired, and Incorrect must be compared under the same light. The repaired material matches Correct while Base Color remains unchanged.

EX24 — normal maps

Break: Import the same normal pixels as ordinary color, use the wrong sampler type, or invert the project’s expected green channel. Introduce only one of these faults per assessed specimen.

Fix: Use Normal Map compression, linear sampling, the normal sampler, and the documented tangent-space convention.

Verify: Move the light around the asset. Highlights and small-scale detail match Correct from multiple directions.

EXMAT — materials in Maya and Unreal

Break: Choose one controlled fault: reorder Maya material slots; omit a slot during export; assign the wrong Unreal material; or change Opaque/Masked/Translucent behavior.

Fix: Repair the authoritative Maya assignment or Unreal setting—not both—and reimport when the source contract changed.

Verify: Material slot order, silhouette, sorting/overdraw behavior, and one unaffected texture remain correct.

EXLOD — LODs and visibility

Use the Smithsonian Page Induction Coil as the detailed source and SimpleInstancing as the assembly/optimization companion.

Correct: A silhouette-preserving LOD chain with documented triangle targets, sensible screen-size thresholds, stable material slots/collision, and intentional bounds/cull distance.

Break: Duplicate the mesh and use exactly one fault: remove lower LODs; make a reduction destructive; place thresholds too close/far apart; lose a material on a lower LOD; or inflate bounds so culling never occurs.

Fix: Generate or import LODs, preserve silhouette-critical regions, restore slot/collision contracts, and tune thresholds while watching mesh statistics.

Verify: Capture triangle count and active LOD at near/mid/far distances. Check for popping, material changes, shadow changes, and collision regressions. Explain that Simplygon-style grouped optimization is a later automation pipeline, not a manual one-off trick.

EX20 — geometry integrity

Break: The seven existing museum assets already isolate flipped normals, non-manifold edges, duplicate faces, open boundaries, non-oriented surfaces, non-manifold shells, and degenerate triangles. Do not add several faults to one mesh.

Fix: Diagnose in Unreal, repair the owning component in Maya, run Cleanup/normal checks, export, and reimport without changing UVs, pivot, scale, or material IDs.

Verify: The targeted diagnostic passes and at least two controlled properties remain identical.

EXA and EX21 — skeletal animation and morph targets

The Correct/Incorrect display assets are present. Full interaction requires a skeletal inspector carrying Skeletal Mesh, animation/AnimBP, playback rate, looping, materials, inspection transform, and morph state.

The fork repair pass reconnects the copied Morph Cube and animation display actors to their local assets. run_INCORRECT_truncated is deliberately tagged EXA_TRUNCATED_SOURCE_CLIP_REQUIRED: its missing dedicated truncated clip was not replaced with a misleading substitute. Do not assign that particular station until a deliberately shortened source clip is authored and verified.

Break/fix: Keep skin weights, animation keys, component animation mode, playback rate, skeleton compatibility, and morph topology as separate faults. Students repair only the owning layer.

Verify: Compare at least two complete loops or the full morph range. Confirm skeleton identity, materials, transform, and unaffected animation data.

EXNIAGARA — staged extension

No project-authored Niagara Correct/Incorrect pair currently exists. Author one small system before assigning this station.

Recommended first pair: a bounded looping sprite or mesh effect. Duplicate Correct and break either fixed bounds, spawn rate, renderer material, or simulation space. Keep one fault per Incorrect version. Show particle count and visibility evidence. Mention VATs as an advanced Houdini-to-Niagara/Unreal playback route; do not require VAT repair until the class has received that pipeline lesson.

Interaction limitations before mass conversion

  • The current item child supports one static mesh.
  • Shared painting meshes need component material overrides copied into inspection.
  • Learn More must resolve from a stable exhibit/source actor ID rather than mesh identity.
  • Skeletal assets require a skeletal inspector.
  • Z-fighting and grouped comparisons require a composite inspector.
  • Interaction bounds must remain independent of display scale.

Until those capabilities exist, leave the original Correct/Incorrect displays visible and use interaction only for stations whose payload can be preserved faithfully.

Student-created exhibit option

Treat a complete original exhibit as a midterm/final option. Require provenance-cleared sources, one controlled fault, Correct/Incorrect states, neutral diagnostic writing, an interaction popup, repair instructions, verification evidence, and a reset path. For the immediate Lab 2 assignment, require one repair plus documentation rather than a complete exhibit build.
