UE imagery used in the illustrated material process diagram

The images are real Unreal Engine editor screenshots published by Epic Games. They were retrieved September 8, 2026. They are not captures of the local museum project. The composition uses rectangular crops, labels, and arrows; UI contents and rendered surfaces were not reconstructed or generated.

The walnut-floor screenshots show related documentation examples at different settings, rather than an asserted single captured frame. The instance image demonstrates controls for another Material; it is not presented as the parent of the walnut-floor preview. Texture thumbnails are sample-node previews, not full-resolution source texture exports. The normal preview's blue color is reproduced as shown in the UE source. Its appearance alone should not be taught as a pass/fail test for a normal-map import.

Teaching notes

The texture rows match the visible graph's Base Color, Roughness, Normal order. The external arrows identify data entering the Material graph as a group; the real UE connections inside the screenshot show the actual destinations.

The top path distinguishes generated HLSL from compiled GPU programs. The optional instance branch demonstrates parameter inheritance and assignment, not a separate source of geometry. The displayed sphere is explicitly labeled as a Material preview. Scene geometry, lighting, and display processing contribute to final appearance.

Use the numbered groups as progressive reveals if adapting this into slides. The full image works as a reference diagram; zoom into the graph when teaching individual node connections.
